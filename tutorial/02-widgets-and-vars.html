02 · 控件交互、复选框与 vars 控形

Atlas Hybrid Canvas 中的每一张控件卡片既可以是静态笔记/待办清单，也可以是用几行 JS 驱动的动态交互组件——甚至可以通过 vars 直接改写自己的标题、类型标签、主题色、宽高与画布坐标。

卡片交互与防误触设计

  • 整卡可拖、双击编辑：默认按住卡片任意非按钮区域均可直接拖动；双击标题或正文才进入原地编辑态，按 Esc 或点外部退出。
  • 固定右上角 Lock + 扁平无位移操作栏：平时右上角只固定留一个锁图标（锁定后禁止拖动与删除）；鼠标悬停时「还原 / 设置 / 复制 / 删除」以无边框无阴影的扁平形态在锁左侧渐显，标题零位移。
  • 支持 0 入口 / 0 出口端口：在右侧属性检查器中可以把 inputPorts 或 outputPorts 减到 0 个（例如纯数据源卡片可设为 0 入口、1 出口）。
  • 超长内容内部滚动：WidgetNode.tsx 主体区设置了 max-h-[420px] overflow-y-auto nowheel，长列表在卡片内部平滑滚动，不会裁切内容，也不会抢占画布滚轮缩放。

整行可点击的待办复选框

在任意普通控件正文或背景文本框里输入以下任意语法，都会自动渲染为自定义 SVG 复选框（支持缩进子任务）： 

- [] 紧凑写法（方括号内可无空格）
- [ ] 标准未完成项
  - [x] 带缩进的已完成子任务（自动加删除线）
* [X] 也兼容 * 与 + 列表符

点击方格或点击整行文字都会立即切换勾选状态并持久化到 IndexedDB；背景文本框关闭编辑模式烘焙到底层 Canvas 后，会同步渲染为清晰的 ☐ 与 ☑。

Code-as-UI：用 vars.contents 声明流式界面

只要在控件的「统一脚本」里给 vars.contents 赋值数组，卡片就会自动切换为声明式流式 UI；嵌套子数组 [ ... ] 表示水平并排一行： 

vars.contents = [
  { type: 'text', text: '当前计数：' + (vars.count || 0), align: 'center', bold: true, color: '#1D4ED8' },
  [
    { type: 'input', id: 'noteInp', bind: 'draft', placeholder: '输入内容按回车提交…' },
    { type: 'button', id: 'addBtn', label: '+1', width: 64, variant: 'primary' }
  ]
];

on('addBtn', () => { vars.count = (Number(vars.count) || 0) + 1; });
onSubmit('noteInp', (val) => { vars.lastNote = val; vars.draft = ''; });

用 vars 直接驱动控件自身形态（type / title / width / height / pos）

src/core/layeredStore.ts 中的 resolveEffectiveNodes() 会将脚本写入的保留变量实时投影到节点属性上，并自动从底部变量胶囊列表中隐藏这些布局键：

保留变量名 类型与边界 实时效果与冲突规则
vars.type / vars.categorystring修改左上角类型徽标文字（type 优先于 category）。
vars.titlestring实时修改卡片标题。
vars.colorCSS 颜色字符串实时修改顶部边框与类型徽标主题色。
vars.width / vars.height数字，钳位 180–1400 / 100–1200四舍五入并安全钳位，防止脚本写非法数值撑爆画布。
vars.pos / vars.x / vars.y{ x, y }、[x, y] 或数字移动控件世界坐标并刷新 ChunkManager 索引；若同时写，显式 x/y 覆盖 pos。
vars.lockedboolean动态锁定或解锁卡片位置。
脚本控形与手动操作不打架：当用户手动拖动卡片、拉边框缩放或双击改标题时，clearConflictingRuntimeVars() 会自动清除 runtimeVars 里对应的冲突布局键（同时完整保留 score 等业务变量），绝不会把手动操作弹回。
