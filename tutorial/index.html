Atlas Hybrid Canvas 完整架构与使用教程

这套离线静态教程面向开发者与重度使用者，分 4 个章节把 Atlas Hybrid Canvas 的混合无限画布渲染、控件脚本与 vars 控形、连线数据通路（DAG + Worker 池）、双层 IndexedDB 存储、Go 协同房间与防 SSRF 代理全部讲透。

五章导读

CHAPTER 01
混合无限画布与渲染原理
讲清 512×512 分块索引、迟滞 LOD（<32% / >38%）、零频闪拖拽机制、HiDPI 清晰背景字与背景图自动等比压缩。
CHAPTER 02
控件交互、复选框与 vars 控形
讲清整卡拖动/双击编辑、0 端口配置、整行可点复选框（- [] / - [x]）、流式 vars.contents 与 vars.type/title/width/height/pos 控形。
CHAPTER 03
连线数据通路、跨控件联动与 Worker 沙箱
讲清 widgets.inputs(portId?)、emitDownstream、DAG 环路拦截、常驻 6-Worker 池、26 词安全黑名单与脚本信任审核弹窗。
CHAPTER 04
双层存储、多人协同与后端安全
讲清 IndexedDB 300ms 防抖、BroadcastChannel 指纹防回环、50 步安全撤销栈、room-go (rev, cid) CRDT 与 /api/proxy 鉴权限流。
CHAPTER 05
画布内置示例拆解与二次开发实战
逐个拆解画布上 4 组实时示例控件的源码原理，并给出新增模板、扩展流式 UI 块、注入新沙箱 API 与写单测的完整二开步骤。

常用快捷键与操作速查

快捷键 / 操作 触发效果 细节说明
Ctrl+K / Cmd+K 打开全局搜索与区块跃迁弹窗 可模糊搜节点/注释标题，也可直接输入 1,-1 或 0,0@0.8 跳到指定 Chunk 与缩放比。
Ctrl+Z / Ctrl+Y 撤销 / 重做（最多 50 步） 在输入框内聚焦时自动放行浏览器原生文本撤销，不误撤画布。
按住 Shift 拖框 框选多个控件批量移动 未按 Shift 时拖空白画布为平移视口。
按住卡片拖动 / 双击文字 移动卡片 / 进入原地编辑 避免误触进入编辑态；按 Esc 或点击外部退出编辑。
滚轮缩放到 < 32% 切入 Macro 宏观瓦片视图 卸载全部上层 DOM 节点，改由底层 Canvas 绘制瓦片与贝塞尔连线箭头。

源码目录速查

路径 核心职责
src/App.tsx顶层工作台容器：协调 React Flow、LOD 切换、脚本调度、导入导出与协同弹窗。
src/canvas/ChunkUnderlayCanvas.tsx底层穿透 Canvas：60 FPS 跟随视口绘制网格、HiDPI 背景文字/等比插图、宏观色块与连线箭头。
src/canvas/WidgetNode.tsxReact Flow 交互控件：支持动态多端口、整行复选框、vars.contents 流式 UI 与内部滚动。
src/core/chunkManager.ts / chunkTileCache.ts512×512 空间分块索引与离屏 LRU 瓦片缓存（淘汰主动释显存）。
src/core/layeredStore.ts / idbStorage.ts双层状态合并、vars 形态投影、手动修改清理冲突变量、IndexedDB 异步防抖与跨页签同步。
src/core/scriptSandbox.ts常驻 Worker 池沙箱、26 词黑名单、即时语法预检与 DAG 环路检测。
src/hooks/useBlueprintHistory.ts（50 步安全撤销栈）与 useOverlaySync.ts（防回环写盘同步）。
server/ & room-go/Express 防 SSRF 代理与保存鉴权服务；Go WebSocket 多人协同房间与确定性 CRDT 存储。
tests/6 份自动化单元测试（17 条用例），通过 npm test 秒级回归。
