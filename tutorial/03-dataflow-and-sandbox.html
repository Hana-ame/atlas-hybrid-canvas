03 · 连线数据通路、跨控件联动与 Worker 沙箱

控件之间的连线不只是视觉装饰——它本身就是一条声明式数据管道。下游脚本可以按入口端口直接读取上游的正文（body）与变量（vars），上游也可以沿出口连线向下游推送事件，且全部运行在隔离的常驻 Web Worker 池中。

连线数据通路 API（零硬编码 ID）

API 作用与返回值
widgets.inputs(portId?)返回连入当前控件（或指定入口如 'in-1'）的上游控件数组，每项含 id / title / body / vars / edgeId / fromPort / toPort / edgeLabel。
widgets.outputs(portId?)返回从当前控件出口连出的下游控件数组。
emitDownstream(event, payload, portId?)沿出口连线向所有下游控件投递事件，下游用 on(event, (payload, meta) => ...) 接收。
widgets.get(id) / vars(id) / list()按 ID 或全量遍历读取画布上任意控件快照。
widgets.create(spec) / connect() / remove()在脚本中动态生成子控件、建立连线或删除控件。
emit(id, ev, data) / broadcast(ev, data)向指定控件 ID 定向投递或向全画布带脚本控件广播事件。
canvas.setAnnotationBg / Color / Text / Image通过注释 ID 动态修改底层背景色块、文字颜色、内容或插图（本地叠加层生效）。

自动触发机制

当你勾选上游清单复选框、编辑上游正文、点击上游控件按钮或新建 / 删除连线时，调度器会自动将最新的 peerOverrides 与 edges 注入下游连线控件并触发刷新（最大递归深度 4 层），无需手动点刷新按钮。

DAG 有向无环图校验

为防止 A → B → C → A 成环导致数据流无限递归，每次在画布上拖端口建边时，onConnect 都会先执行 validateDagConnection(edges, source, target)：从 target 出发做广度优先搜索（BFS），一旦检测到路径能回到 source（或 source === target 自环），立即拦截连线并弹出通知。

隔离 Web Worker 池与四重脚本安全防线

  1. 常驻可复用 Worker 池：scriptSandbox.ts 最多缓存 3 个空闲 Worker 并复用同一个 Blob URL，消除链式事件频繁冷启动带来的延迟与 GC 抖动；每次 onmessage 都在局部作用域重新声明 vars / handlers / logs，无状态串改。
  2. 5 秒硬超时强杀：任意死循环脚本超过 5000ms 立即 worker.terminate() 并移出复用池，绝不卡死主线程 UI。
  3. 26 词黑名单 + 原型键过滤：静态拦截 window / document / fetch / localStorage / indexedDB / eval / Function / __proto__ 等 26 个高危标识符；检查器编辑框下方实时展示语法与安全预检结果。
  4. 外部脚本信任审核（ScriptTrustModal）：通过 JSON 导入或远端协同房间同步进来的新脚本默认处于锁定态，必须经用户逐条审阅代码并点击「信任」后才允许执行。
