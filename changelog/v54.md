# v54 — 扩大缩放器碰撞箱 + 四角等比缩放 / 四边自由拉伸（SmartNodeResizer）

> 发布日期：2026-11-23

## 改进（Changed）

- **四角保持比例、四边自由拉伸**（`src/canvas/SmartNodeResizer.tsx`、`src/canvas/WidgetNode.tsx`、`src/canvas/AnnotationNode.tsx`）：
  - 基于 `@xyflow/react` 原生 `NodeResizeControl` 封装 `SmartNodeResizer`，替换原单一 `keepAspectRatio` 的 `NodeResizer`。
  - 四角手柄（`top-left` / `top-right` / `bottom-left` / `bottom-right`）开启 `keepAspectRatio={true}`，拖拽角落严格保持宽高比缩放。
  - 四边控制线（`top` / `right` / `bottom` / `left`）设为 `keepAspectRatio={false}`，拖拽四边可自由调整单向宽或高。
- **大幅扩大缩放器碰撞箱**（`src/index.css`）：
  - 四边控制线通过伪元素扩展为 `16px` 宽/高透明命中带（`±8px`）；四角手柄视觉增大至 `12×12px`（触屏 `18×18px`）并通过伪元素扩展至 `32×32px`（触屏 `42×42px`）透明热区。
  - 层级明确分层：边线 `z-12` < 角点 `z-20` < 连线端口 `z-30`，既好抓角和边，又不遮挡端口连线。
