# v35 — 三环流式裁剪与方向预测预加载、分块精准脏缓存与重媒体离屏休眠

> 发布日期：2026-11-23

## 新增（Added）

- **三环视锥裁剪与方向预测预加载（`src/core/viewportCulling.ts`）**：
  - **Ring 0（重媒体激活区）**：当前视口外扩 `320px` + 顺平移方向额外 `256px`，仅在此范围内挂载重型 PDF `<iframe>`；
  - **Ring 1（轻 DOM 预加载区）**：当前视口外扩 `1 Chunk (512px)` + 顺平移方向额外前瞻 `512px`，提前热挂载轻型交互节点，平移不闪现、屏外不常驻；
  - **Ring 2（空闲瓦片预烘焙区）**：`ChunkUnderlayCanvas` 在宏观视图空闲帧通过 `requestIdleCallback`（`timeout: 120ms`，每次最多烘焙 `2` 张）预热周边 1 环离屏瓦片。
- **单元测试**：新增 `tests/viewportCulling.test.ts`（3 条）并在 `tests/chunkManager.test.ts` 新增分块精准脏标记测试（1 条），自动化测试总数增至 25 条。

## 改进（Changed）

- **分块级签名脏缓存（`src/core/chunkManager.ts`）**：`rebuild()` 为每个 `512×512` 分块计算轻量内容签名，未改动分块保留原 `version` 与 `dirty = false`；`App.tsx` 移除常规节点编辑时的全量 `tileCache.clear()`，大幅提高离屏瓦片缓存命中率。
- **SVG 连线视锥裁剪（`src/App.tsx`）**：`rfEdges` 通过 `filterVisibleEdges()` 仅渲染至少一端已挂载在可见/预加载环中的连线，消除远端数百条不可见 SVG 边的渲染开销。
- **PDF 离屏休眠与按需脚本首帧渲染**：远端离屏的 `PdfViewerBlock` 自动卸载重型 `<iframe>` 为轻量休眠占位（保留页码与总页数），移近 Ring 0 秒恢复；首帧脚本自动渲染优先仅执行 Ring 1 预加载区内的脚本控件，远端脚本控件进入预加载环时再按需触发。
