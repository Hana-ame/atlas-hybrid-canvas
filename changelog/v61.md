# v61 — 统一 DEV / PROD 的 `/api/*` 拦截器入口

## 改动摘要
- **`src/main.tsx`**：移除 `if (import.meta.env.PROD)` 分支，改为无条件同步调用 `installMockApi()`，同步更新入口注释。
  - **未配置 `VITE_BACKEND_WS_URL`**：无论开发态（`npm run dev`）还是生产构建，均由 `mockApi` 在浏览器内直接运行 `apiCore.ts` + IndexedDB 作为本地后端。

- 消除了此前“DEV 跳过拦截器直连 HTTP、PROD 走 `mockApi`”的环境行为分叉，保证开发与生产链路完全一致。
