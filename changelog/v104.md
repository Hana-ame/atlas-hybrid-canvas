# v104 — 连线多样式支持与右侧连线样式设置面板

> 发布日期：2026-11-27

## 新增（Added）

- **连线多样式数据模型与几何渲染**（`src/core/types.ts`、`src/core/edgePath.ts`、`src/canvas/ControllableEdge.tsx`）：
  - `BlueprintEdge` 新增 `pathType`（`'smooth'` 平滑曲线 / `'straight'` 直线 / `'step'` 直角折线）、`strokeStyle`（`'solid'` 实线 / `'dashed'` 虚线 / `'dotted'` 点线）、`strokeWidth`（线宽）及 `animated`（独立流动动画开关），同时保持对旧版 `dashed` 字段的兼容。
  - `buildControlPointEdgePath()` 新增直线与直角折线路径计算（含控制点与弧长中点标签定位），新增 `resolveEdgeStrokeDasharray()` 映射 SVG `strokeDasharray`。
  - `ControllableEdge` 选中态在标签胶囊旁（无标签时自动显示迷你胶囊）提供「设置连线样式」齿轮按钮（`Settings2`）。
- **连线样式设置面板 `EdgeInspectorPanel`**（`src/components/EdgeInspectorPanel.tsx`、`src/App.tsx`）：按需分包的右侧设置面板，支持实时修改连线标签、路径形状、线型、线宽（`1.5` / `2.2` / `3` / `4` px）、颜色（预设色板 + 自定义取色器）、流动动画与单线双向（`<——>`），并支持删除连线与撤销/重做（`pushHistory`）。

## 改进（Changed）

- **`ControllableEdge` 线宽尊重自定义配置**（`src/canvas/ControllableEdge.tsx`）：将原硬编码 `2.2 / 3` 改为读取 `style.strokeWidth`（选中或悬停时在此基础上 `+0.8px` 高亮），确保粗细设置即时生效。

## 验证

- `tests/uiComponents.test.ts` 新增 `Edge styles (pathType, strokeStyle, strokeWidth) and EdgeInspectorPanel render and resolve properly` 测试，验证 `resolveEdgeStrokeDasharray`、直线/直角折线路径、`ControllableEdge` 自定义样式属性与 `EdgeInspectorPanel` 控件渲染。
