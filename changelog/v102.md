# v102 — 支持同源相对 WebSocket 路径，内置 `elyfn` 函数调用卡与 `git-gateway` 仓库看板卡（含定时刷新），可选 WebRTC P2P 开关

> 发布日期：2026-11-27

## 新增（Added）

- **`elyfn` 函数调用与目录控件 `ElyfnRunnerBlock`**（`src/canvas/ElyfnRunnerBlock.tsx`、`src/canvas/contentBlockRegistry.tsx`、`src/core/widgetTemplates.ts`）：按需分包注册 `elyfn_runner` 积木与内置模板 `tpl-elyfn-runner`。挂载时自动请求 `GET <baseUrl>/catalog` 拉取只读函数目录，支持**定时自动刷新**（`关 / 15s / 30s / 60s / 5m`，后台页签与离屏自动休眠）、下拉选择或手动填写 `folder/fn`、可选会话内存级 `Bearer EXEC_KEY`、编辑 JSON 入参并调用 `POST /:folder/:fn`，执行状态与结果通过 `onBatchUpdateVars` 写回节点 `vars` 触发下游联动。
- **`git-gateway` 仓库看板控件 `GitGatewayBlock`**（`src/canvas/GitGatewayBlock.tsx`、`src/canvas/contentBlockRegistry.tsx`、`src/core/widgetTemplates.ts`）：按需分包注册 `git_gateway` 积木与内置模板 `tpl-git-gateway`。挂载时自动请求 `GET <baseUrl>/repos` 拉取白名单仓库与别名目录，支持**定时自动刷新**（模板默认 `30s`，支持 `关 / 15s / 30s / 60s / 5m`，后台页签与离屏自动休眠）、切换仓库、在 **PR / CI** 与 **TODO** 双页签间切换，并可按 PR 在线查询 `/prs/<n>/ci` 与失败日志 `/prs/<n>/logs?tail=60`。
- **类型与 Agent 安全校验**（`src/core/types.ts`、`src/core/agentOps.ts`）：为 `ContentLeafBlock` 补充 `ContentElyfnRunnerBlock` 与 `ContentGitGatewayBlock`（含 `autoRefreshSec` / `bindAutoRefresh`）类型定义，并在 `validateLeafBlockSafety()` 中复用 `isSafePollUrl` 校验两类积木的 `baseUrl`。
- **WebRTC P2P 网格可选开关**（`src/core/runtimeConfig.ts`、`src/core/roomClient.ts`、`Dockerfile`、`.env.example`）：新增 `parseEnableWebRtcP2p()` / `enableWebRtcP2p()`（读取 `VITE_ENABLE_WEBRTC_P2P`）；关闭时 `CollaborativeRoomClient` 不再初始化 `RoomWebRtcMesh`，全部协同流量纯走 WS 服务端中继。Docker 构建默认 `false`，本地开发默认 `true`。

## 改进（Changed）

- **相对路径与同源 WebSocket 自动推导**（`src/core/runtimeConfig.ts`）：扩展 `normalizeWsUrl()`，支持相对路径（如 `/ws`）与关键词 `auto` / `same-origin`，在浏览器运行时按 `window.location.protocol`（`https:` → `wss:`，其余 `ws:`）与 `window.location.host` 动态解析，同时拦截协议相对地址 `//...`；配合 Docker 单容器部署实现一次构建、跨域名/HTTPS 免重编运行。

- **运行时镜像瘦身与竞态防护**（`package.json`、`ElyfnRunnerBlock.tsx`、`GitGatewayBlock.tsx`）：将 Vite 已打包的前端依赖（`@xyflow/react`、`lucide-react`、`react`、`react-dom`）移至 `devDependencies`，服务端运行镜像仅保留 `express`/`ws`/`dotenv`；两张新积木补齐 `AbortController` + 递增序号防并发竞态。
