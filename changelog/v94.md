# v94 — 统一默认端口全景对齐、消除 Shift 键位冲突并补齐双击回归测试

> 发布日期：2026-11-25
> 对应审查报告：`changelog/v93-review-01.md`

## 视觉与交互一致性修复

- **统一默认端口配置，消除全景端点跳变**：将 `DEFAULT_INPUT_PORTS` / `DEFAULT_OUTPUT_PORTS` 抽至 `src/core/edgePath.ts` 并由 `WidgetNode.tsx` 与 `resolveNodePortY()` 共享，未显式声明 `inputPorts` 的默认节点（如 `node-lore-north`、`node-ops-south`）在缩远切入 `macro` 视图时仍精确对齐 33.3% / 66.7%。
- **消除 `Shift` 键位冲突**：移除 `handleEdgeDoubleClick` 中的 `ev.shiftKey` 分支，改为调用纯函数 `decideEdgeDoubleClickAction()`，统一为「普通双击与 `Shift` 双击放行给标签编辑/框选，仅 `Alt + 双击` 与 `+` 手柄插入控制点」。
- **加固拖拽会话边界与残留草稿清理**：`createControlPointDragSession()` 入口校验 `index` 整数边界、`handleMove` 校验 `Number.isFinite(flowPos.x/y)`，且 `ControllableEdge.tsx` 重启非新建拖拽前主动重置 `draftPoints`。
- **消除全景箭头重复贝塞尔公式**：`ChunkUnderlayCanvas.tsx` 起止双向箭头直接复用 `evalCubicBezier(lastSeg, 0.92)` 与 `evalCubicBezier(segs[0], 0.08)`。
