# v65 — 默认蓝图内置媒体与交互控件示例（ZONE E）+ 单测与代码审查修复

## 改动摘要

### 默认蓝图示例（`src/core/seedBlueprint.ts`）
- 在现有 ZONE D 下方新增 **ZONE E · 媒体与交互控件示例区**（`y = 1270..1940`，与既有节点零重叠）：
  - `demo-image-node`（图片节点示例，内置 SVG 演示图与悬停工具条）
  - `demo-video-node`（视频节点示例，支持 MP4/WebM 直链与本地视频上传）
  - `demo-slider-node`（拖动条控件示例，强度 + 倍率双滑块）
  - `demo-pad2d-node`（2D Pad 拖动板示例，二维坐标触控板 + 双击归中）
  - `demo-image-button-node`（四态图片按钮示例，内置 `on / off / hover / click` 四张区分贴图）
  - `demo-controls-monitor`（下游实时监视器，经 3 条连线 `edge-ctrl-slider` / `edge-ctrl-pad2d` / `edge-ctrl-imgbtn` 实时汇总拖动条、2D Pad 与图片按钮状态）

### 代码审查发现并同步修复的 3 个缺陷（详见 `changelog/v65-review-01.md`）
1. **`ImageNodeBlock.tsx` 灯箱全屏被 React Flow transform 困住**：改为 `createPortal(..., document.body)` 真正全屏覆盖视口，并补上 `Esc` 快捷键关闭。
2. **`Pad2DControlBlock.tsx` 底部 X/Y 输入框无法键入负号**：改用本地草稿态 `xDraft` / `yDraft` 配合 `inputMode="decimal"`，允许输入 `"-"` 或清空重输，在输入合法数字、失焦或回车时平滑对齐提交。
3. **`SliderControlBlock.tsx` 触摸中断丢失提交**：补齐 `onPointerCancel` 回调，确保触屏拖动被打断时仍会提交最终值并触发脚本与下游联动。

### 新增测试（`tests/seedBlueprint.test.ts`）
- 校验默认种子蓝图包含 5 类新控件示例节点与下游监视器；
- 校验全部种子节点两两零重叠、全部连线端点有效；
- 现有 `scriptSandbox.test.ts` 自动覆盖所有新增种子节点脚本的语法编译与安全扫描。
