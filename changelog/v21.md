# v21 — 工程化防坑整改（测试基建 / 模块拆分 / 存储与 Worker 加固 / 安全限流）

> 发布日期：2026-11-23

## 新增（Added）

- **前端与代理层自动化测试套件（P0）**：在 `package.json` 新增 `npm test`（`tsx --test tests/*.test.ts`），新增 5 份自动化测试共 13 条用例：
  - `tests/crdt.test.ts`：`(rev, cid)` 确定性裁决、`computeRecordDiff` 与远端 CRDT 合并；
  - `tests/taskList.test.ts`：`- []` / `- [ ]` / `- [x]` / `- [X]` / 缩进子任务解析、切换与 Canvas 符号映射；
  - `tests/chunkManager.test.ts`：`512×512` 空间分块索引与视口裁剪；
  - `tests/proxySecurity.test.ts`：SSRF 内网 IPv4/IPv6/云元数据拦截、白名单校验与危险请求头拒绝；
  - `tests/scriptSandbox.test.ts`：危险全局词拦截、DAG 环路检测，以及**全量种子蓝图与内置模板脚本的语法/安全编译预检**。
- **独立领域 Hooks 拆分（P1）**：
  - `src/hooks/useBlueprintHistory.ts`：从 `src/App.tsx` 抽离 50 步深拷贝撤销/重做历史栈；
  - `src/hooks/useOverlaySync.ts`：从 `src/App.tsx` 抽离本地叠加层防抖写盘与多标签页同步生命周期。
- **有向无环图（DAG）环路检测（P3）**：`src/core/scriptSandbox.ts` 新增 `validateDagConnection()`，`App.tsx` 在 `onConnect` 拖线建边时自动拦截自环与传递环路。
- **即时脚本语法与安全预检（P3）**：`src/core/scriptSandbox.ts` 新增 `validateScriptSyntax()`，`NodeInspectorPanel.tsx` 在统一脚本编辑框下方实时展示安全拦截、语法报错或通过提示。
- **服务端 `/api/proxy` 限流与调用方鉴权（P2）**：`server/server.ts` 新增按 IP 滑动窗口限流（`PROXY_RATE_LIMIT_PER_MIN`，默认 30 次/分钟，返回 `429` 与 `Retry-After`）及可选 `X-Proxy-Token` 常量时间鉴权（`PROXY_CLIENT_TOKEN`），同步更新 `.env.example`。
- 新增 `CHANGELOG.md`；新增 `ScriptTrustModal`（脚本信任审计）与 `SearchJumpModal`（`Ctrl+K` 搜索跳转）。

## 改进（Changed）

- **常驻可复用 Web Worker 池（P2）**：不再在每次事件后销毁重建 Worker，改为最多复用 3 个空闲 Worker 并复用 Blob URL；仅在超时（>5s）或运行异常时立即强杀重建。
- **IndexedDB 防抖写盘 + `BroadcastChannel` 跨页签同步（P2）**：`layeredStore.ts` 新增 `scheduleSaveLocalOverlay`（默认 300ms 防抖）、`flushLocalOverlaySave`（`beforeunload` / `pagehide` 兜底刷盘）与 `subscribeCrossTabOverlay`。
- **离屏瓦片显存主动释放（P2）**：`chunkTileCache.ts` 在 LRU 淘汰与 `clear()` 时显式将离屏 `<canvas>` 的 `width` / `height` 置 `0`。
- **长内容控件内部滚动（P3）**：`WidgetNode.tsx` 主体区增加 `max-h-[420px] overflow-y-auto nowheel`。

## 已知遗留

- `useBlueprintHistory` 与 `useOverlaySync` 仅完成实现与导入，`App.tsx` 尚未实际调用；撤销栈与跨页签同步在本版未生效。`App.tsx` 仍直接使用 `saveLocalOverlay`（同步写盘）而非防抖版本。
- `server/server.ts` 的 `proxyRateHits` Map 无过期清理，不同 IP 条目永久累积，长期运行存在缓慢内存增长（仅影响自托管 server，不影响 Pages 静态部署）。
- `deploy-pages.yml` 未把 `npm test` 纳入 CI 门禁；`tsconfig.json` 的 `include` 不含 `tests`，测试文件的类型错误不会被 `tsc --noEmit` 捕获。
