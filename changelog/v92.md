# v92 — 修复连线控制点右键复活、空提交污染、监听泄漏与全景走线同步

> 发布日期：2026-11-25
> 对应审查报告：`changelog/v91-review-01.md`

## 交互与稳定性修复

- **修复右键删除控制点后松手立即复活**：`ControllableEdge.tsx` 的 `startDragControlPoint` 与中点 `+` 手柄 `onPointerDown` 均严格限制仅响应左键（`ev.button !== 0` 直接返回），删除控制点前同步清理挂起拖拽态。
- **消除单击/双击导致的无意义撤销栈与 CRDT 广播污染**：拖拽仅在实际坐标变化或新建控制点时提交；`App.tsx` 的 `handleUpdateEdgeControlPoints` 改为先校验节点存在且 `areControlPointsEqual` 为否后才调用 `pushHistory()` 与 `setBase()`。
- **修复拖拽中卸载导致的 `window` 监听器泄漏**：通过 `dragCleanupRef` 统一管理 `pointermove`/`pointerup`/`pointercancel` 清理函数，组件在切入 `macro` LOD 或删边卸载时自动解绑。
- **修复双向连线起点图标重叠**：仅在 `!markerStart` 时渲染起点实心锚点圆，避免与双向连线起点箭头重叠。

## 全景视图与 Agent / MCP 同步

- **全景 `macro` 模式沿控制点样条绘制**：`edgePath.ts` 导出 `computeControlPointBezierSegments()`，`ChunkUnderlayCanvas.tsx` 缩远后与近景 SVG 使用完全同源的 Catmull-Rom 分段曲线与末端切线箭头，ZONE F 避让走线在鸟瞰模式下不再穿过卡片。
- **补齐 Agent / MCP 对 `controlPoints` 的自描述与读取**：`getAgentToolSchema()` 声明 `controlPoints`、`summarizeBlueprintForAgent()` 返回非空 `edges[].controlPoints`，并将 `connect_edge` 的空数组 `[]` 归一化为 `undefined`。
