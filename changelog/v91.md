# v91 — 连线可拖拽控制点、起点实心锚点与 ZONE F 状态机避让走线

## 变更内容
- **数据模型（`src/core/types.ts`、`src/core/agentOps.ts`）**：`BlueprintEdge` 新增 `controlPoints?: EdgeControlPoint[]`，随 CRDT 协同同步、支持撤销/重做，并支持 Agent 通过 `connect_edge` 传入自定义控制点。
- **样条路径几何（`src/core/edgePath.ts`）**：无控制点时保持平滑贝塞尔曲线；有控制点时使用 Catmull-Rom 转三次贝塞尔样条平滑穿过全部控制点，并将标签精确放置在整条路径弧长 50% 处。
- **交互式连线组件（`src/canvas/ControllableEdge.tsx`、`src/App.tsx`）**：
  - 每条连线起点绘制带白边的实心锚点圆，配合终点箭头清晰标识「从哪连向哪」；
  - 悬停或选中连线时高亮整条路径并显示所有可拖拽控制点手柄及每段中点「+」插入手柄；
  - 支持双击连线任意处新增控制点、拖拽控制点 60fps 实时弯折、双击或右键控制点删除，松手后一次性落盘并同步。
- **ZONE F 状态机示例走线优化（`src/core/seedBlueprint.ts`）**：为 `cancel`、`pause`、`resume`、`reset`、`restart` 五条回退/交叉连线预设独立避让走廊控制点，不再从卡片下方穿过或互相遮挡标签。
- **测试覆盖**：新增 `tests/edgePath.test.ts` 与 `tests/uiComponents.test.ts` 中 `ControllableEdge` 渲染测试。
