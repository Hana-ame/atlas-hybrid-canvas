# Atlas Hybrid Canvas v72 — 剩余隐患清零版

## 本次修复与加固
1. **修复 `/api/auth/session` 签名/验签密钥不一致 + 补齐前端自动续期闭环**
   - `server/server.ts`：`verifyProxyClientToken` 统一使用 `authSessionSecret || proxyClientToken` 作为 HMAC 验签密钥，修复仅配置 `PROXY_CLIENT_TOKEN`（未单独设 `AUTH_SESSION_SECRET`）时服务端签发出的会话令牌被自身拒绝的 Bug。
   - `src/core/apiClient.ts`：新增 `initAuthSession()`、`refreshAuthSession()`、`stopAuthSessionRefresh()`、`getAuthSessionState()`，支持并发请求去重、TTL 80% 处提前静默续期，以及本地 mock/开放模式无感降级。
   - `src/main.tsx`：应用启动时自动触发 `initAuthSession()`。
2. **清除最后一处图片 `FileReader.readAsDataURL` 内存炸弹**
   - `src/canvas/AnnotationNode.tsx`：移除本地文件上传转 base64 的 `FileReader` 路径，改为纯外链 URL 输入（经 `isSafeImageUrl` 校验，仅允许 `http/https`、同源 `/api/` 及轻量内置 SVG），与 `ImageNodeBlock`、`VideoNodeBlock` 彻底对齐零大二进制驻留策略。
3. **补齐 React 错误边界（全画布 + 单节点双层隔离）**
   - 新增 `src/components/CanvasErrorBoundary.tsx`，支持 `app` 级兜底恢复与 `node` 级内联重试。
   - 在 `src/main.tsx` 包裹 `<App />`，并在 `src/canvas/WidgetNode.tsx` 包裹单节点内容块，防止单个损坏控件或异常渲染导致整张画布白屏。

## 验证结果
- `tsc --noEmit`（排除离线环境缺失 `ws` 类型的 `server/roomServer.ts`）：0 报错。
- `npm run build`：通过。
- 单元测试（含新增 `tests/authSessionLifecycle.test.ts`）：全量通过。
