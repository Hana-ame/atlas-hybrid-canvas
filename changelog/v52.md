# v52 — 基于仓库 v51 基线合并 PDF 查看器体验升级（输入可点击 / 多 DPI 防发糊 / 整卡拖拽 / 预加载零闪烁）

> 发布日期：2026-11-23
> 基线：完全以用户提供的 `51.zip`（含 Node WS `roomServer.ts`、`apiCore.ts`、`proxyHeaders`、`256MB` 解包内存上限及全部保护文件）为准

## 合并的新功能与修复

- **修复 URL 输入框不可点击聚焦**（`src/index.css`、`src/canvas/PdfViewerBlock.tsx`）：
  - 在 `src/index.css` 中为 `.react-flow input / textarea` 恢复 `touch-action: auto`、`user-select: text`、`cursor: text`，并为按钮与 `.nodrag` 恢复 `touch-action: manipulation`，解除 `.react-flow { touch-action: none; }` 对输入框聚焦的阻断。
  - 为一次性 URL 输入框与页码输入框补齐 `nodrag nopan nowheel`、冒泡拦截及 `onClick` 主动 `focus()`。
- **修复放大控件/缩放画布发糊（多分辨率按需超清渲染）**（`server/pdfUnpack.ts`、`server/server.ts`、`src/core/pdfHelper.ts`、`src/core/pdfClientUnpack.ts`、`src/canvas/PdfViewerBlock.tsx`）：
  - 服务端 `pdfUnpack.ts` 完整保留 `51.zip` 的 **256MB 全局内存字节上限 LRU 逐出** 与 15 份文档上限，升级为 `pdfinfo`/`mutool` 秒级识别精确总页数 + `GET /api/pdf/:id/page/:page?dpi=150|220|300|400` 按需单页渲染与 `(page@dpi)` 双层 LRU 缓存（单文档最多 80 张）。
  - 纯前端兜底 `pdfClientUnpack.ts` 升级为 `1100 / 1700 / 2500 / 3600px` 动态像素档位（最高 5× scale，单边上限 4096px）。
  - `PdfViewerBlock.tsx` 通过 `ResizeObserver` + React Flow `useStore((s) => s.transform[2])` × `devicePixelRatio`（120ms 防抖）动态升级清晰度，同时完整保留 `51.zip` 的 `proxyHeaders(...)` 鉴权头注入。
- **除按钮与输入框外整卡均可拖动**（`src/canvas/PdfViewerBlock.tsx`）：
  - 移除外层容器与图片视口上的 `nodrag nopan` 和事件拦截，图片设置 `pointer-events-none`；仅输入框与按钮拦截拖拽，按住图片区或空白背景即可直接移动 PDF 控件。
- **后台预加载下一页 + 零闪烁切图**（`src/canvas/PdfViewerBlock.tsx`）：
  - 服务端模式通过 `preloadDecodedImage()` 等待 `img.decode()` 完成后原子切换图片，并后台预加载 `page + 1`（优先）与 `page - 1`；前端兜底模式同样后台静默预渲染相邻页，保留上一帧直至新页就绪后原子替换，杜绝切页与高清升级闪烁。
