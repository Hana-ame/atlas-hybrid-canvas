# v26 — 修复首屏脚本渲染竞态、移除多余画布锁与常驻状态条

> 发布日期：2026-11-23

## 修复（Fixed）

- **修复首屏部分脚本控件空白未渲染的异步竞态**：`src/App.tsx` 此前在 IndexedDB `loadLocalOverlay()` 恢复完成前即触发所有脚本控件的首帧 `render`，导致早完成的 Worker 结果被随后到达的 `setOverlay(savedOverlay)` 覆盖且因 `renderedScriptsRef` 已登记而不再重跑。现已改为严格等待 `overlayHydrated === true` 后再执行首帧脚本渲染，彻底消除首屏空白。

## 改进（Changed）

- **移除右下角冗余画布总锁按钮**：`<Controls position="bottom-right" showInteractive={false} />` 隐藏 React Flow 默认的全局交互锁（每张控件卡片右上角已有独立锁按钮），右下角仅保留缩放与居中视图控制。
- **常驻底部「就绪」提示条改为按需浮动 Notify**：取消初始「就绪：…」常驻提示条，改为仅在触发实际操作通知时弹出浮动 Toast，并在 `3.5s` 后自动消失，平时不占用画布视觉空间。
