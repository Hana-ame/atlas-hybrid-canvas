# v107 — 解耦连线线型与流动动画、提升控件历史浮窗层级与防误触发修复

> 发布日期：2026-11-27

## 修复（Fixed）

- **解耦连线 `strokeStyle` 与 `animated` 状态**（`src/App.tsx`、`src/components/EdgeInspectorPanel.tsx`）：在设置面板切换「实线 / 虚线 / 点线」后，不再因 `dashed` 字段同步写入而隐式打开或关闭流动动画（仅对未设置过 `strokeStyle` 的旧版 `dashed` 连线保留兼容回退），并补充单测断言。
- **提升打开历史浮窗时的卡片层级**（`src/App.tsx`）：将 `widgetHistoryNodeId === entity.id` 的控件节点 `zIndex` 由 `10` 提升至 `60`，避免右侧邻居节点卡片遮挡展开的 `WidgetHistoryPopover`。
- **隔离设置齿轮按钮双击事件**（`src/canvas/ControllableEdge.tsx`）：为「设置连线样式」按钮补充 `onDoubleClick={(ev) => ev.stopPropagation()}`，防止快速连点切换面板时误触发标签内联输入框。
