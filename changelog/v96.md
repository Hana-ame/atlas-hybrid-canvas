# v96 — 连线标签改为画布内联编辑，控制手柄彻底隔离画布拖拽，README 同步到当前版本

> 发布日期：2026-11-26
> 对应审查报告：`changelog/v95-review-01.md`

## 新增（Added）

- **画布内联标签编辑器**：双击连线本体或标签胶囊，在 `(labelX, labelY)` 原地出现输入框。`Enter` / 失焦提交，`Esc` 取消；中文输入法组合期（`isComposing`）忽略 `Enter`，`editClosedRef` 一次性标志防止提交与失焦重复落盘。标签编辑链路不再调用 `window.prompt` / `window.alert`（模板命名等其它场景的 prompt 保持不变）。
- **选中态与编辑态集中管理**：`App.tsx` 新增 `selectedEdgeIds` 与 `editingEdgeLabelId`，`onEdgesChange` 镜像 React Flow 的 `select` 变更，删边时同步清理选中与编辑态，`onPaneClick` 关闭编辑态。
- **「+」手柄标签避让**：手柄与标签胶囊距离小于 `28px` 时下移 `22px`，且新增控制点的落盘坐标使用偏移后的 `handleX / handleY`，显示与写入一致。
- **独立回归测试**：新增 `tests/inlineLabelIndependent.test.ts`（5 条），覆盖避让正反两面、编辑态手柄显隐、pointer-events 分层、只读态行为与源码级守护。

## 改进（Changed）

- 控制点手柄与「+」手柄统一加 `nodrag nopan edge-control-handle`、显式 `pointer-events="all"`、`touch-action: none`，`onMouseDown` / `onTouchStart` 阻断冒泡；外发光、「+」内十字、起点实心圆改为 `pointer-events: none`。
- `window` 拖拽监听改用捕获阶段注册/注销，保证多层 SVG 命中时仍能收到 `pointerup`；卸载时同时清理 `hoverLeaveTimerRef`。
- 悬停退出增加 `120ms` 延迟，光标在曲线与标签胶囊之间移动时手柄不再闪烁。
- README 从 `v12` 更新到 `v96`：新增「连线交互（控制点与标签）」操作表、架构分层中的 `ControllableEdge`、目录中的 `ControllableEdge.tsx` / `edgePath.ts` / `agentOps.ts`，并补上 `npm test` 命令。

## 修复（Fixed）

- 移除编辑标签时的原生 `prompt`，避免浏览器弹窗阻断画布交互、遮挡中文输入法候选框。
- 空标签与未变更标签不再压入撤销栈（`normalized` 比对先于 `pushHistory()`）。
- 删除连线后不再残留对应的内联编辑态或选中态。

## 已知遗留 / 未生效项

- `computeControlPointBezierSegments()` 仍为 uniform 参数化（`(p2 - p0) / 6`），疏密悬殊的控制点会让曲线冲出包围盒约 22px（见 `changelog/v95-review-01.md`）。本版未改几何。
- 编辑标签期间若远端协同写入同一条连线的 `label`，`useEffect` 会用远端值覆盖本地草稿；多人同时编辑同一标签时可能丢失正在输入的内容。本版未改，记入遗留。
