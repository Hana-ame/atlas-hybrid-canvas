# v97 — 连线样条升级 Centripetal Catmull-Rom，收敛极端拐点过冲

> 发布日期：2026-11-26
> 对应审查报告：`changelog/v96-review-01.md`

## 改进（Changed）

- `computeControlPointBezierSegments()` 由 uniform 参数化（`(p2 - p0) / 6`）升级为 **Centripetal Catmull-Rom（α = 0.5）**：节点间距取 `sqrt(hypot(Δx, Δy))`，端点用镜像ghost点补一阶邻域，控制柄按 `d1² / (3·d1·(d1+d2))` 与 `d3² / (3·d3·(d3+d2))` 加权，不再因相邻间距悬殊而放大切线。
- 退化保护：`d2 < 1e-6` 时退化为两端点直连；首/末端 `d1` 或 `d3 < 1e-6` 时改用 `/3` 等分，避免除零与 `NaN`。
- 路径端点链、标签弧长采样、`segmentMidpoints`、全景 Canvas 共用几何等对外契约均未变，SVG path 仍严格穿过 `[起点, ...控制点, 终点]`。

## 修复（Fixed）

- 极端疏密控制点（如 `(0,0) → (5,0) → (5,300)`）的样条最低点由约 `y = -22.2` 收敛到约 `y = -0.66`，不再冲出控制点包围盒。
- 独立测试 ⑫ 从「遗留行为锁定」转为正向回归：断言 `minY >= -2`，并在文件头注明 α = 0.5 的参数化口径。

## 已知遗留 / 未生效项

- 编辑标签期间远端协同更新同一条边 `label` 会覆盖本地草稿（见 `changelog/v96.md`），本版未改。
- 节点/连线选中态与编辑态仍由 `App.tsx` 两个独立 state 维护，未见跨用户同步需求。
