# Atlas Hybrid Canvas v82 — 实测补修 `roomServer.ts` 崩溃漏洞与全量 E2E 集成测试通过

## 实测发现并修复的真实 Bug
1. **修复 `server/roomServer.ts` WebRTC 信令处理崩溃（`ReferenceError: cid is not defined`）**
   - `handleMessage` 中 `rtc_offer` / `rtc_answer` / `rtc_ice` 分支错误引用了未在作用域内的 `cid` 变量，导致收到任意 WebRTC 信令帧直接抛未捕获异常；已改为从 `room.members.get(socket)?.cid` 安全读取发送方 `cid`。
2. **修复 `server/roomServer.ts` `join(...)` 参数不匹配类型错误**
   - 修正 `wss.handleUpgrade` 中多传 `clientIp` 的调用，使全仓 `npx tsc --noEmit`（含 `server/roomServer.ts`）零排除、零报错通过。
3. **新增真实服务端进程级 E2E 集成测试（`tests/serverIntegration.test.ts`）**
   - 直接以 `node dist-server/server.mjs` 启动真实后端，覆盖 `/api/health`、未授权 401、非法 Origin 403、`/api/auth/session` `HttpOnly` Cookie 签发、按路径发布蓝图、`Sec-WebSocket-Protocol` 子协议建连水合、`/history` 版本记录与 `/rollback` 后 REST + WS `replace: true` 同步。

4. **修复 `join()` 清空预水合房间状态 Bug（由 E2E 实测捕获）**：先经 REST 发布蓝图再由首位 WS 成员入房时，`join()` 原先无条件 `states.set(roomName, new RoomState())` 会清空已同步状态；现改为 `if (!states.has(roomName))` 保留已有状态。
