# v100 — 固定控件按钮与正文布局，将 vars 改为单行横向滚动条

> 发布日期：2026-11-26

## 改进（Changed）

- **按钮执行态不再改变宽度与布局**（`src/canvas/WidgetNode.tsx`、`src/canvas/contentBlockRegistry.tsx`）：按钮点击进入 `isBusy` 状态时保留原始 `btn.label` / `block.label`，仅将前置图标切换为 `Loader2` 旋转指示器，避免原先替换为 `'执行中…'` 导致按钮宽窄跳变并引发多按钮折行错位。
- **隔离正文、按钮与变量区的垂直耦合**（`src/canvas/WidgetNode.tsx`）：移除常规卡片正文展示容器上的 `flex-1` 拉伸（改由底部空白双击占位区承接余白），避免变量写入导致正文压缩、进而把按钮整体向上挤压跳动；带按钮或变量的非脚本卡片始终保留固定高度底栏。
- **变量展示改为独立单行横向滚动条**（`src/canvas/WidgetNode.tsx`、`src/index.css`）：将原有 `flex-wrap` 多行变量胶囊替换为固定 `h-8` 底部 `vars-scroll-row` 单行横向滚动栏（`flex-nowrap overflow-x-auto whitespace-nowrap`，变量为空时显示 `vars: 暂无` 占位，支持鼠标滚轮横滚与轻量细滚动条且带 `nodrag nopan nowheel` 防误拖/防缩放），彻底杜绝变量增多或返回长 JSON 时撑开卡片、打乱按钮布局的问题。

## 验证

- `tests/uiComponents.test.ts` 新增并更新回归测试，验证忙态按钮保留原标签、`vars-scroll-row` 单行横向不换行渲染、空变量占位保留固定高度以及脚本按钮阻塞状态一致性。
- 本地执行 `npm run typecheck`、`npm run build:server`、`npm run build:mcp`、`npm run build` 全部通过；除依赖系统 `mutool`/`pdftoppm` 的 `tests/pdfUnpack.test.ts` 外，其余 197 条 `test()` 用例全部通过。
