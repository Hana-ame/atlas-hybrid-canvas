# v88 — 补齐 Agent 闭环：只读状态接口、WS 刷盘防覆盖、乐观锁、模板实例化、dryRun 与 MCP Server

## 解决的 5 项短板
1. **Agent 专用只读状态接口（`GET /api/rooms/*/agent/state` 与 `GET /api/agent/state`）**：仅需 `X-Agent-Api-Key` 即可读取低 Token 消耗的房间摘要（`nodes`/`annotations`/`edges`/`templates`）与当前 `revision`（加 `?full=1` 可取完整蓝图），不再依赖浏览器会话 Cookie。
2. **杜绝覆盖人类未落盘 WS 实时编辑 + 乐观锁**：
   - `server/roomServer.ts` 新增 `flushRoomSnapshot(roomName)`，在 Agent 读写前先把 WS 内存态（1.5 秒防抖窗口内尚未写盘的编辑）刷入并合并；
   - `server/server.ts` 增加按房间串行队列 `runSerializedForRoom` 与 `expectedRevision` 乐观锁（版本不符返回 `409 Conflict` + `currentRevision`）。
3. **模板实例化与结构化积木（`src/core/agentOps.ts`）**：新增 `create_from_template`（复用全部 22 套 `BUILTIN_TEMPLATES`），并为 `create_widget` / `update_widget` 增加 `blocks` 结构化积木字段，无需 Agent 手写原始脚本。
4. **零依赖标准 MCP stdio 服务端（`server/mcpServer.ts` + `npm run build:mcp`）**：实现 JSON-RPC 2.0 MCP 协议，暴露 `atlas_list_templates`、`atlas_inspect_room`、`atlas_apply_ops`、`atlas_rollback_room` 四个工具，支持直接接入 Claude Desktop / Cursor / Gemini CLI。
5. **`dryRun: true` 预演模式**：校验整批操作并计算自动布局坐标（`bounds` + `preview`），不落盘、不递增版本、不向在线协作者广播。
