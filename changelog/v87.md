# v87 — 面向外部 AI Agent 的声明式画布操作引擎与工具接口

## 新增能力
- **`src/core/agentOps.ts`**：实现纯函数原子批处理引擎 `applyAgentOperations()` 与标准 JSON Tool Schema `getAgentToolSchema()`，支持 8 类高层操作：
  - 控件：`create_widget`（缺省坐标自动防重叠布局）、`update_widget`（默认浅合并 `defaultVars`）、`delete_widget`（级联清理悬空连线）；
  - 背景注释/插图：`create_annotation`、`update_annotation`、`delete_annotation`（自动校验 `imageUrl` 安全性）；
  - 拓扑连线：`connect_edge`、`delete_edge`（支持单向与 `bidirectional` 双向连线）。
- **服务端接口（`server/server.ts`、`server/fileStore.ts`、`.env.example`）**：
  - `GET /api/agent/schema`：自描述标准工具定义，供 OpenAI / Gemini / MCP Agent 直接注册调用；
  - `POST /api/rooms/<roomPath>/ops` 与 `POST /api/ops`：校验 `X-Agent-Api-Key`（环境变量 `AGENT_API_KEY`，留空回退 `BLUEPRINT_SAVE_KEY`），原子落盘到统一房间存储、写入 `action: 'agent'` 修改日志支持一键回档，并实时向同房间在线 WS 成员广播。
- **测试覆盖**：新增 `tests/agentOps.test.ts` 与 `tests/serverIntegration.test.ts` 端到端用例，验证鉴权拒绝、批量创建/修改、WS 实时推送与历史审计回档。
