# Atlas Hybrid Canvas v73 — WebSocket 全链路鉴权与容器化交付

## 本次补齐
1. **WebSocket `/ws` 握手鉴权闭环（消除协同房间未授权接入漏洞）**
   - `server/roomServer.ts`：`attachRoomServer` 新增 `verifyToken` 校验回调，在 HTTP `upgrade` 阶段提取 `?token=` 或 `X-Proxy-Token`，校验失败直接回 `HTTP/1.1 401 Unauthorized` 并断开连接。
   - `server/server.ts`：向 `attachRoomServer` 注入 `verifyProxyClientToken`，让 HTTP 路由与 WebSocket 协同/RPC 通道共用同一套鉴权策略（兼容无状态 HMAC 会话令牌与静态 `PROXY_CLIENT_TOKEN`）。
   - `src/core/roomClient.ts` & `src/core/rpcClient.ts`：建连与断线自动重连时均通过 `appendProxyTokenQuery` 自动附带最新有效令牌。
2. **健康检查探针与容器化部署就绪**
   - `server/server.ts`：新增 `GET /api/health` 探针，返回服务存活状态、运行时长与当前鉴权模式。
   - 新增生产级多阶段 `Dockerfile`（Node 20 Alpine、非 root 运行、`/data` 持久化卷、`HEALTHCHECK` 探测 `/api/health`）并补全 `.env.example`（补充 `AUTH_SESSION_SECRET` 与 `ATLAS_DATA_DIR`）。
