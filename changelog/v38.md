# v38 — 移除引擎硬编码 DAG 拦截，改为控件脚本自主校验（`onValidateConnect` + `widgets.checkDag`）

> 发布日期：2026-11-23

## 改进（Changed）

- **解除引擎全局硬编码 DAG 拦截**：`src/App.tsx` 的 `onConnect`、`op.op === 'connect'` 与 `src/core/scriptSandbox.ts` 的 `widgets.connect()` 不再全局强杀环路连线。普通状态机、思维导图或双向反馈控件现在可自由建立环路连接，递归执行由 `depth <= 4` 与 Worker `5000ms` 超时兜底。
- **改为控件自带代码校验（`onValidateConnect`）**：连线建立前，主线程通过 `validateConnectionByWidgets()` 向起点与终点控件脚本派发 `validateConnect` 事件（附带 `source / target / fromPort / toPort / fromNode / toNode / wouldCycle / cyclePath`）；若任一控件脚本注册了 `onValidateConnect(fn)` 并返回 `false` 或 `{ ok: false, reason }`，则按控件自身规则拦截并展示其自定义提示；未注册钩子时默认放行。
- **更新 `AGENTS.md` 代码约定**：同步将第 137 行更新为「默认允许自由拓扑，DAG 或端口约束由控件脚本通过 `onValidateConnect()` + `widgets.checkDag()` 自主声明」。

## 新增（Added）

- **沙箱拓扑自检 API**：`src/core/scriptSandbox.ts` 暴露 `widgets.checkDag(fromId?, toId?)`、`widgets.topoSort()` 与 `onValidateConnect(fn)`，并导出纯函数 `computeTopologicalOrder()`。
- **示例演示**：ZONE D「③ 下游消费者：连线数据汇总」在其自身脚本中注册了 `onValidateConnect`，演示如何仅对需要 DAG 的特定控件自主禁环，同时不影响画布其余控件自由连环。
- **单元测试**：`tests/scriptSandbox.test.ts` 新增 2 条 `cyclePath` 与 `computeTopologicalOrder` 用例，自动化测试总数增至 27 条。
