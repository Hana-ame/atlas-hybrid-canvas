# Atlas Hybrid Canvas v75 — 13 项深度审查隐患全部清零

## 安全与鉴权修复
1. **修复 `POST /api/auth/session` 单配 `AUTH_SESSION_SECRET` 认证绕过（高危）**：`server/server.ts` 改为只要启用任意鉴权（`PROXY_CLIENT_TOKEN` 或 `AUTH_SESSION_SECRET`），签发接口必须配置并校验通过 `PROXY_CLIENT_TOKEN`，彻底堵死无凭证白嫖 1 小时签名令牌漏洞；同步修正 `.env.example` 说明。
2. **消除 URL 长期令牌泄露，切换 `HttpOnly` Cookie 鉴权**：`POST /api/auth/session` 下发 `HttpOnly; SameSite=Strict; Path=/` 的 `atlas_session` Cookie；`/api/proxy`、`/api/pdf/*` 与 `/ws` 统一从 `X-Proxy-Token` 请求头或 `atlas_session` Cookie 验权；`appendProxyTokenQuery` 不再拼接长期 bearer token 到 URL；更新 `tests/authSessionLifecycle.test.ts` 反向断言禁止 URL 令牌泄露。
3. **消除静态模式 405 噪音**：`src/main.tsx` 仅在配置了 `VITE_BACKEND_WS_URL` 或 `VITE_PROXY_CLIENT_TOKEN` 时触发 `initAuthSession()`，同时 `src/core/apiCore.ts` 兜底处理 `POST /api/auth/session`。

## 协同与稳定性修复
4. **修复协同 `recordSyncedMeta` 登记虚高 `rev`**：`src/hooks/useRoomCollaboration.ts` 三处（node / ann / edge）均改为登记远端原始记录，不再用本地高 `rev` 污染远端同步水位。
5. **消除服务端与客户端字段级 CRDT 语义分歧**：`server/roomServer.ts` 的 `RoomState.upsert` 直接复用 `src/core/crdt.ts` 的 `mergeRecordFieldsLWW`，两端 100% 同源一致。
6. **修复断线重连热循环**：`src/core/roomClient.ts` 引入 5 秒稳定存活窗口（`STABLE_CONNECTION_MS`），连上即断不再归零 `reconnectAttempts`。
