# v63 — 新增图片节点、视频节点与拖动条控件

## 新增能力
- **图片节点（`ImageNodeBlock.tsx` + 声明式 `type: 'image'` + 内置模板「图片节点」）**：
  - 支持图片 URL 加载与本地图片选择（`<= 4MB` 自动转 `data:` URL 写入本地叠加层持久化，超大图走 `blob:` 并随组件卸载自动释放）；
  - 悬浮操作条支持等比完整（`contain`）/ 铺满裁切（`cover`）切换、大图灯箱预览与更换图片，接入 `mediaActive` 三环视口裁剪；
  - 通过 `isSafeImageUrl()` 拦截 `javascript:` / `data:text/html` 等危险协议。
- **视频节点（`VideoNodeBlock.tsx` + 声明式 `type: 'video'` + 内置模板「视频节点」）**：
  - 支持 MP4 / WebM / OGG 直链与本地视频文件上传播放；
  - 提供 `0.5× / 1× / 1.5× / 2×` 倍速切换、循环播放、静音切换与更换视频源；
  - 接入 `mediaActive` 三环视口裁剪，移出活跃视口自动暂停播放，卸载自动释放 `blob:` URL，并由 `isSafeVideoUrl()` 拦截危险协议。
- **拖动条控件（`SliderControlBlock.tsx` + 声明式 `type: 'slider'` + 内置模板「拖动条控件」）**：
  - 既可作为独立拖动条节点拖入画布，也可嵌入任意脚本节点的 `vars.contents`（支持 `min` / `max` / `step` / `unit` / `label` / `accentColor`）；
  - 严格隔离画布拖拽事件（`nodrag nopan nowheel`），拖动中实时更新数值，松手后入撤销栈、触发脚本 `onChange` 并自动通知下游连线节点联动；
  - 通过 `clampSliderValue()` / `formatSliderValue()` 处理边界归一化与浮点步进精度。
- **状态与容器适配**：
  - `WidgetNode.tsx` 将单块 `pdf` / `image` / `video` 统一升级为沉浸式铺满容器（`isImmersiveMedia`）；
  - `layeredStore.ts` 的 `sanitizeEphemeralBlobVars()` 同步清理刷新后失效的 `blob:` 图片/视频链接。
