# v1 – v15 — 混合画布基础架构里程碑

> 归档：由原 `CHANGELOG.md` 拆分而来

## 架构

融合三大子系统：

- **React Flow v12**（`meso` / `micro` 原生 DOM 交互层）
- **AtlasCanvas**（`512×512` 空间分块 + LRU 瓦片 + 迟滞 LOD + Worker 沙箱 + SSRF 代理）
- **`room-go/`**（Go 协同房间 + `(rev, cid)` CRDT）

## 关键修复与迁移

- 根治拖拽频闪（`applyNodeChanges` 保留 `measured` / `dragging` + `useStoreApi().subscribe()`）。
- 全量迁移至异步 IndexedDB。
- 支持 `X-Blueprint-Save-Key` 保存鉴权、HiDPI 清晰背景字、0 入口/0 出口端口配置、右上角固定 Lock + 扁平无位移 hover 工具栏与完整架构文档集。
