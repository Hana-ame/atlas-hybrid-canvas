# v70 — 架构深化升级（App 拆解与分包 + 字段级协同 + 二进制 WS RPC + 签名会话鉴权）

## 改动摘要

### 1. 拆解 `App.tsx` 与 Vite Vendor 分包（`vite.config.ts`、`src/hooks/useRoomCollaboration.ts`、`src/hooks/useBlueprintIO.ts`）
- 将协同房间连接/重连/CRDT 增量收发抽离至 `useRoomCollaboration.ts`，将蓝图导入导出与 Chunk 坐标深链抽离至 `useBlueprintIO.ts`，`App.tsx` 瘦身至 2,665 行。
- 配置 `vite.config.ts` `manualChunks` 独立拆出 `vendor-react`、`vendor-xyflow`、`vendor-icons` 与 6 个按需懒加载 chunk，首屏主 JS 包从 655 kB 降至 **229.46 kB**（gzip 72.48 kB），彻底消除构建体积告警。

### 2. 多人协同字段级合并与断线自动重连（`src/core/crdt.ts`、`src/core/roomClient.ts`、`server/roomServer.ts`）
- `VersionedRecord` 新增 `fieldRevs?: Record<string, FieldStamp>`，`mergeRecordFieldsLWW()` 按字段粒度执行 `(rev, cid)` LWW 裁决（并发修改同一卡片不同字段时双方修改均可保留），同时向后兼容无 `fieldRevs` 的旧帧；`RoomState.upsert()` 服务端同步升级。
- `CollaborativeRoomClient` 新增 `reconnecting` 状态、指数退避自动重连（500ms–15s，最多 8 次）以及 200 条上限的离线操作缓冲队列，断线期间的编辑在重连后自动补发。

### 3. WS RPC 原生二进制帧（`src/core/rpcBinaryFrame.ts`、`src/core/rpcClient.ts`、`server/roomServer.ts`、`server/server.ts`）
- 新增 `[4B uint32 BE headerLen][UTF-8 JSON meta][raw bytes]` 二进制帧编解码器，在 `__rpc__` 通道上直接收发原生二进制负载；文本/JSON 走 UTF-8 文本帧，PDF/PNG 等二进制请求与响应不再走 base64，消除约 33% 传输膨胀与编解码内存拷贝。

### 4. 无状态 HMAC-SHA256 会话鉴权（`server/authSession.ts`、`server/server.ts`）
- 新增 `issueSignedSessionToken()` 与 `verifySignedSessionToken()`（`timingSafeEqual` + 过期校验），服务端暴露 `POST /api/auth/session` 签发 1 小时短时效签名令牌，`verifyProxyClientToken()` 同时兼容 `AUTH_SESSION_SECRET` 签名令牌与旧版静态 `PROXY_CLIENT_TOKEN`。
