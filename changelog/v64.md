# v64 — 新增 2D Pad 拖动板与四态图片按钮控件

## 新增能力
- **2D Pad 拖动板（`Pad2DControlBlock.tsx` + 声明式 `type: 'pad2d'` + 内置模板「2D Pad 拖动板」）**：
  - 复刻 `pose-studio-3d` 的 Color-picker 风格二维触控板：深色 `#11141b` 面板、四象限径向微光、25% 网格与中心基准线、实时十字准星以及拖动放大（`1.18×`）的发光拖拽球；
  - 支持 `setPointerCapture` 连续平滑拖动、双击回中归零、右上角一键复位，以及底部 X / Y 数值直输微调；
  - 严格带 `nodrag nopan nowheel` 隔离画布拖拽，松手后自动入撤销栈、触发脚本 `onChange(['padX', 'padY'])` 并联动下游连线节点。
- **四态图片按钮（`ImageButtonBlock.tsx` + 声明式 `type: 'image_button'` + 内置模板「图片按钮 (4态)」）**：
  - 用图片替代传统按钮，完整支持 **`on` / `off` / `hover` / `click`** 四种独立状态贴图，优先级 `click > hover > on > off`，缺失时安全回退；
  - 支持切换型（`toggle: true`，点击翻转 `on`/`off` 状态并触发脚本 `on(id)` 与下游联动）和点按型（`toggle: false`）；
  - 悬停右上角提供四态贴图快捷配置面板，可直接粘贴 URL 或本地上传图片替换任意状态贴图，内置 4 张区分鲜明的演示 SVG 贴图开箱即用。
- **工具函数与测试（`src/core/mediaHelper.ts`、`tests/mediaHelper.test.ts`）**：
  - 新增 `mapPadPointerToValues()`、`mapPadValuesToPercent()`、`resolveImageButtonState()`、`resolveImageButtonSrc()` 纯函数及对应单元测试。
