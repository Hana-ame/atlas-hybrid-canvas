# v49 — 彻底移除 PDF 内置浏览器 iframe，重构为逐页解包图片查看器（fit 控件大小 · 零滚动条 · 一次性输入）

> 发布日期：2026-11-23
> 基线：基于用户提供的仓库最新 v48（保留 v42 修复、`src/core/scriptAudit.ts`、v48 `/api/proxy/binary` 接线与 `docs/SCRIPT_API_GUIDE.md`）

## 历史版本 Blame 溯源（明确追责）

- **Blame `v31`（`changelog/v31.md` / `v31-review-01.md`）**：首次实现 PDF 控件时偷懒采用了浏览器内置 `<iframe src={iframeSrc}>` + `buildPdfIframeSrc()` 方案，直接引入了浏览器自带的多页滚动浏览视图与滚动条，并在外链带 `X-Frame-Options` / `Content-Disposition: attachment` 时报错。
- **Blame `v32`（`changelog/v32.md`）**：继续沿用 `<iframe src>` 浏览器内置阅读器（保留原生滚动条），并擅自增加了可反复展开的「换源」工具栏，违背一次性加载需求。
- **Blame `v35`（`changelog/v35.md`）**：在 `<iframe>` 之上叠加离屏休眠逻辑，继续固化了内置浏览器阅读器架构，未做 PDF 逐页解包。
- **明确驳回外部 Agent 幻觉需求**：
  1. 驳回「双击图片放大，再次双击缩小」—— 用户真实需求是 **严格 fit 控件大小（控件拉大图片等比放大，控件缩小图片等比缩小）**，不做双击缩放状态。
  2. 驳回「必须能够滚动浏览 / 保留滚动条」—— 用户真实需求是 **零滚动条、仅靠左右翻页与页码跳转** 的干净界面。

## 核心改动

- **彻底清除 `<iframe>` 渲染与辅助函数**：
  - `src/canvas/PdfViewerBlock.tsx`：移除全部 `<iframe>` / `<embed>` / `<object>`，改为纯单页 `<img>` 渲染。
  - `src/core/pdfHelper.ts`：彻底删除 `buildPdfIframeSrc()`，新增 `isUnpackedPdfTemplate()` 与 `buildPdfPageImageUrl()`。
- **服务端 PDF 真解包引擎**（`server/pdfUnpack.ts`、`server/server.ts`）：
  - 使用 `execFile` 参数数组安全调用 `pdftoppm`（缺失时自动回退 `mutool`）将 PDF 光栅化为逐页 144 DPI PNG 图片（15 份文档 LRU 缓存，临时目录在 `finally` 必清理）。
  - 新增 `POST /api/pdf/unpack`（远程 URL，复用限流、`X-Proxy-Token`、DNS 私网拦截、`redirect: 'manual'` 拦 3xx，以及独立不共用超时 `AbortController` 的 `readResponseBufferWithLimit` 50MB 流式上限）、`POST /api/pdf/unpack-upload`、`GET /api/pdf/:id/meta` 与 `GET /api/pdf/:id/page/:page`（`image/png` + `X-Content-Type-Options: nosniff`）。
- **纯前端静态模式兜底解包**（`src/core/pdfClientUnpack.ts`）：
  - 无后端时通过 ESM 动态加载 `pdf.js` 将 PDF 页面渲染至离屏 Canvas 并导出 PNG DataURL 缓存（单文档最多 24 页），绝不回退浏览器 `<iframe>`。
- **仿 Windows 图片查看器 UI（严格 fit 控件 · 零滚动条 · 一次性输入）**（`src/canvas/PdfViewerBlock.tsx`）：
  - **一次性输入**：未绑定来源时居中展示一次性 URL 输入框与本地 PDF 文件选择；成功解包并锁定后输入栏永久消失，不再提供「换源」按钮。
  - **严格 fit 控件大小**：主图使用 `h-full w-full object-contain`，随 `NodeResizer` 拉伸自动等比放大/缩小，无双击放大逻辑。
  - **零滚动条、极简翻页**：全程 `overflow-hidden`，仅保留图片左右两侧悬浮翻页箭头（支持键盘 `←`/`→` 与触屏左右滑动）与底部居中页码 `‹ [当前页] / 共 X 页 ›`。
- **测试覆盖**：新增 `tests/pdfUnpack.test.ts`（实测 2 页 PDF 真实解包输出合法 PNG 字节流）并更新 `tests/pdfHelper.test.ts` 移除 iframe 用例。
