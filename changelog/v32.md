# v32 — PDF 阅读控件沉浸式无框铺满重构与底部「共 X 页」翻页栏

> 发布日期：2026-11-23

## 改进（Changed）

- **零内边距沉浸式铺满**：`src/canvas/WidgetNode.tsx` 识别单 `pdf` 块卡片时自动取消外层主体 padding 与嵌套边框，PDF 视口紧贴卡片边缘铺满，并随 `NodeResizer` 拉伸自动自适应填满高度。
- **底部精致翻页栏与「共 X 页」显示**：`src/canvas/PdfViewerBlock.tsx` 将翻页控制移至卡片最底部，采用圆形 `‹` / `›` 翻页按钮与居中胶囊 `[ 当前页 ] / 共 X 页`（页码可原地输入回车跳转，末页自动禁用下一页）；顶部 URL / 上传 / Proxy 栏在加载后自动收起，可通过底部右侧「换源」随时展开。
- **自动解析 PDF 总页数**：`src/core/pdfHelper.ts` 新增零依赖 `countPdfPagesFromBytes()`，内置演示 PDF、本地上传 PDF 及同源/代理 PDF 均可自动识别精确总页数（跨域受限时优雅显示 `共 ? 页`）。

## 新增（Added）

- `tests/pdfHelper.test.ts` 新增 `countPdfPagesFromBytes()` 单元测试，自动化测试总数增至 21 条。
