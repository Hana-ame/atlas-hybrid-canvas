# v110 — 夜间模式完善与 `PiAgentBlock` 深度画布接合

> 发布日期：2026-11-28

## 变更摘要（Changed / Added）

* **夜间模式（浅色 / 夜间 / 跟随系统）**（`index.html`、`src/index.css`、`src/hooks/useTheme.ts`、`src/App.tsx`、`src/canvas/ChunkUnderlayCanvas.tsx`、`src/canvas/ControllableEdge.tsx`、`src/canvas/PiAgentBlock.tsx`）：
  * 全链路支持 Tailwind v4 `@custom-variant dark`、防闪屏初始化、Canvas 2D 底层瓦片深色重绘与 React Flow `colorMode` 同步。
* **`PiAgentBlock` 升级为可自主运行的画布 Agent 积木**（`src/canvas/PiAgentBlock.tsx`、`src/canvas/contentBlockRegistry.tsx`）：
  * **修复管理员流式断链**：改用带 `X-Pi-Admin-Key` 头的 `fetch()` + `ReadableStream` SSE 解析，实时分栏渲染正文输出、可折叠思考轨迹与工具调用角标。
  * **Canvas 会话级 API Key 管理**：支持在卡片设置中填写 `PI_ADMIN_KEY` 与可选 LLM API Key（仅存当前标签页 `sessionStorage` 并在同标签页多卡片间同步，绝不写入共享 `BaseBlueprint`）。
  * **手动注入 Atlas MCP**：新增「注入 MCP / MCP 已注入」切换按钮，按需向 Pi 会话工作区写入或移除 `.pi/mcp.json`。
  * **无人值守停止条件**：支持配置最大轮数（`maxTurns`）、超时秒数（`maxDurationSec`）、停止正则（`stopRegex`）与默认自动放行（`autoApproveUi`），适配“画好画布 + 设好停止条件即自动跑完”的工作流。
  * **暴露完整 Pi RPC 能力**：新增 `steer` 插话、`follow-up` 排队续跑、`abort` 中断、`compact` 上下文压缩、`fork` 分支、`stats` 用量统计与 `reset`。
  * **宿主机 `pi` 检测与 `elyfn` 一键安装引导**：探测 `/pi/health`，当宿主机未安装 `pi` 时显示提示并提供「调用 elyfn 安装」按钮。
  * **画布上下游数据流接合**：`contentBlockRegistry.tsx` 将上游连线传入的 `vars.input` 透传为 `upstreamInput`（支持一键填入或上游变化自动触发），运行完成时同时回写 `piLastOutput` 与 `output`（`vars.output`）供下游节点消费。
* **架构说明（单一控件 + 组合式内容注册表）**：
  * Atlas 坚持**只有一种通用控件容器 `WidgetNode`**，内部通过 `vars.contents` 与 `contentBlockRegistry.tsx` 组合渲染多种形态（文本、按钮、图表、PDF、`elyfn`、`git-gateway`、`pi_agent`），而不采用面向对象类继承；这样单个控件卡片即可按需混排多个不同积木并共享拖拽、缩放、端口、变量与版本历史。
