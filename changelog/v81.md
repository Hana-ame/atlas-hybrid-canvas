# Atlas Hybrid Canvas v81 — 回档防复活、P2P/WS 帧去重与静态模式历史接口兜底

## 本次修复
1. **修复版本回档 / 权威发布后在线客户端旧节点复活问题**
   - `server/roomServer.ts`：`syncPublishedBlueprint` 广播 `{ t: 'state', blueprint, replace: true }`。
   - `src/core/roomClient.ts` & `src/hooks/useRoomCollaboration.ts`：收到 `replace: true` 的 `state` 帧时清空 `maxSyncedMetaRef` 并整体替换 `base` 与 `prevSyncedBaseRef.current`，不再走并集合并，彻底防止已回档/删除的旧节点被客户端重新上传复活。
2. **消除 WebRTC P2P + WS 双通道重复帧抖动**
   - `src/core/roomClient.ts`：引入有界短期帧去重表（2 秒 TTL、最多 256 条），同一 `upsert_*` / `delete_*` 帧同时经 P2P 与 WS 到达时只分发一次给 CRDT 合并管线。
3. **补齐静态模式 `/api/rooms/*/history` 与 `/api/rooms/*/rollback` 本地兜底及 `POST /api/rollback` 对称路由**
   - `src/core/apiCore.ts`：原生接管 `/api/rooms/*/history`、`/api/history`、`/api/rooms/*/rollback` 与 `/api/rollback`，纯静态模式下打开保存/历史弹窗不再穿透到 CDN 产生 404 噪音。
   - `server/server.ts`：补齐 `POST /api/rollback` 路由，与 `GET /api/history` 保持对称。
