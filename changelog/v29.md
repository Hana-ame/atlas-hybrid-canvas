# v29 — workflow 将 tutorial/ 一并拷入 dist/ 随站点发布

> 发布日期：2026-11-23

## 改进（Changed）

- **教程页正式随站点上线**：`.github/workflows/deploy-pages.yml` 在 `Build` 之后、`Add .nojekyll` 之前新增 `Copy tutorial into dist` 步骤，执行 `cp -r tutorial/. dist/tutorial/`，把 `tutorial/` 下 6 份静态 HTML 拷进构建产物目录，随 `dist/` 一起被 `actions/upload-pages-artifact@v3` 上传、由 Pages 发布。
- **访问路径**：`https://hana-ame.github.io/atlas-hybrid-canvas/tutorial/index.html`，与主站同一子路径前缀。
- **步骤幂等且可降级**：拷贝前先判断 `[ -d tutorial ]`，目录不存在时打印「未找到 tutorial/ 目录，跳过」而不报错退出；拷贝后 `ls -1 dist/tutorial` 输出文件清单到 CI 日志，便于核对实际发布的文件。

## 已知遗留 / 未生效项

- **教程页不进 vite 构建图**：`vite.config.ts` 未改多页入口，`tutorial/` 仍是独立静态目录，靠 workflow 拷贝发布。因此教程页没有构建期资源指纹与压缩，也不参与 `typecheck`。
- **本地开发服务器不提供教程页**：`npm run dev` 下 `/tutorial/` 仍为 404，只在 CI 构建产物与线上站点可见。

## 验证

- **静态链接与资源核查**：6 份 HTML 内所有站内链接均为相对路径（如 `href="01-canvas-architecture.html"`），零绝对路径；零外部资源引用（无 `https://`、无 `.css`/`.png`/`.svg`/`.js` 外链文件），样式与 SVG 全内联，拷入 `dist/tutorial/` 后相对路径可正确解析。
- **改动范围核对**：`git diff` 仅 `.github/workflows/deploy-pages.yml` 一处，新增 12 行，未触及 `src/`、`vite.config.ts`、`package.json`。
- **保护文件未动**：`src/vite-env.d.ts`、`vite.config.ts`、`AGENTS.md` 均无改动。
