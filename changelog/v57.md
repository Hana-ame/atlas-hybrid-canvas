> 发布日期：2026-11-23

## 新增（Added）

- **API 轮询纯逻辑模块**（`src/core/apiPoller.ts`、`tests/apiPoller.test.ts`）：
  - `normalizePollIntervalSec()`：将轮询间隔安全夹紧到 `[2, 3600]` 秒（`0` / 负数 / `NaN` / `Infinity` 退回默认 10 秒）。
  - `isSafePollUrl()`：仅放行 `http/https` 外链与同源 `/api/`，拦截 `javascript:` / `data:` / `file:`。
  - `extractJsonPath()`：支持嵌套路径与数组下标（如 `allowedHosts[0]`、`data.items[1].name`），显式屏蔽 `__proto__` / `constructor` / `prototype` 防原型链污染。
  - `computeBackoffDelayMs()`：连续失败自动指数退避（2^n 倍，封顶 5 分钟），恢复成功后立即重置。
- **API 轮询抓取控件**（`src/canvas/ApiPollerBlock.tsx`、`src/core/types.ts`、`src/canvas/WidgetNode.tsx`、`src/core/widgetTemplates.ts`）：
  - 扩展声明式块 `ContentApiPollerBlock`（`type: 'api_poller'`），左侧模板抽屉新增「API 轮询抓取器（`tpl-api-poller`）」。
  - 支持 URL、GET/POST、间隔秒数、JSON 提取路径、`/api/proxy` 代理开关（自动注入 `proxyHeaders`）、启动/暂停轮询、立即抓取、成功/失败计数与响应预览，并将 `pollLastValue` / `pollStatus` / `pollUpdatedAt` / `pollError` 实时写回节点 `vars` 供下游连线消费。
  - 内置 Single-Flight（`AbortController` + 递增 `seqRef` 防乱序覆盖）、`visibilitychange` 后台页签自动暂停、`mediaActive` 离屏自动休眠与卸载清理。

## 真实 Chromium 浏览器 E2E 边缘测试抓出并当场修复的 3 个 Bug

1. **轮询 `useEffect` 依赖父组件内联回调导致死循环狂刷请求（高危）**（`src/canvas/ApiPollerBlock.tsx`）：
   - 浏览器实测启动 2 秒轮询后，因 `WidgetNode` 内联 `onPollResult` 每次渲染生成新引用，触发 `executePollOnce` 重建并重启 `useEffect`，2.7 秒内狂发 185 次请求。
   - 修复：将 `onPollResult` / `lastValue` / `pathDraft` / `executePollOnce` 收入 `ref`，轮询 `useEffect` 仅监听配置变更；复测 2.6 秒内精确执行 `delta = 2` 次，点击暂停后完全停止。
2. **`mockApi.ts` 在非 HTTP 宿主页（`about:blank` / `srcdoc` / 离线 HTML）URL 解析崩溃**（`src/core/mockApi.ts`）：
   - 浏览器实测 `new URL('/api/proxy/status', window.location.href)` 在 `about:blank` 下直接抛 `Invalid URL`，导致静态/嵌入式预览内 mock API 全部失效。
   - 修复：非 `http(s)://` 宿主页自动回退 `http://atlas.local/` 作为相对路径 base。
3. **输入框失焦提交读取陈旧 React state 闭包**（`src/canvas/ApiPollerBlock.tsx`）：
   - 浏览器实测快速输入并失焦时 `commitInterval` / `commitUrl` 读到上一帧 state；改为直接读取 `e.currentTarget.value` 并同步夹紧。
