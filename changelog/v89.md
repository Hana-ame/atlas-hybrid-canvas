# v89 — 修复 v88 对抗性复查发现的 4 处边界缺陷与实进程 stdio MCP 回归测试

> 对应审查报告：`changelog/v88-review-01.md`

## 修复内容
1. **畸形 URL 编码防御（`server/server.ts`）**：新增 `safeDecodeRoomParam()` 包裹 `decodeURIComponent`，遇到非法百分号编码直接返回 `400 Bad Request`，杜绝未捕获 `URIError`。
2. **WS 未水合空快照防护（`server/roomServer.ts`）**：`flushRoomSnapshot` 仅在 `hydratedRooms.has(roomName) || persistTimers.has(roomName)` 时返回内存快照，防止首次异步水合窗口期空状态遮蔽磁盘数据。
3. **`blocks` 媒体 URL 安全校验（`src/core/agentOps.ts`）**：新增 `validateBlocksSafety()`，对 `image`、`video`、`pdf`、`api_poller`、`image_button`（含嵌套行数组）逐块校验 URL 安全性，拦截 `javascript:` / `blob:` 等危险协议并整批回滚。
4. **回档与 Agent 写操作统一串行化（`server/server.ts`）**：`handleRollbackRequest` 接入 `runSerializedForRoom(roomPath)`，消除并发 `/ops` 与 `/rollback` 的写盘交错。

## 新增回归测试
- `tests/agentOps.test.ts`：新增 `blocks` 危险 URL 拦截负向用例。
- `tests/serverIntegration.test.ts`：新增畸形 `%E0%A4%A` / `%ZZ` 路径返回 `400` 负向用例，以及真实 `spawn` `dist-server/mcp-server.mjs` 子进程走 stdin/stdout 完成 `initialize` → `atlas_apply_ops` → `atlas_inspect_room` 的端到端测试。
