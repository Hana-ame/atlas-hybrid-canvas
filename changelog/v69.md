# v69 — 服务端原子持久化 + 控件注册表重构 + 懒加载分包与单线双向连线

## 改动摘要

### 1. 服务端原子落盘持久化（`server/fileStore.ts`、`server/server.ts`、`server/roomServer.ts`）
- 新增零外部依赖原子文件存储 `server/fileStore.ts`（串行写队列 + 临时文件 + `fs.rename` 原子替换），数据目录默认 `.atlas-data/`（可通过 `ATLAS_DATA_DIR` 覆盖，已加入 `.gitignore`）。
- `server/server.ts` 将 `sharedStore` 从内存版切换为 `createFileBlueprintStore(DATA_DIR)`，发布的权威蓝图与修订号重启后自动水合不丢失。
- `server/roomServer.ts` 新增可选 `persistDir`：协同房间发生变更时 600ms 防抖落盘至 `<DATA_DIR>/rooms/<safeName>.json`，停机自动刷盘，重启后首次入房自动恢复房间快照。

### 2. 控件注册表与 Hook 拆解（`src/canvas/contentBlockRegistry.tsx`、`src/canvas/WidgetNode.tsx`、`src/hooks/useCanvasShortcuts.ts`）
- 将 `WidgetNode.tsx` 中 10 类声明式 `vars.contents` 渲染逻辑抽离为可扩展注册表 `CONTENT_BLOCK_REGISTRY` 与 `IMMERSIVE_BLOCK_TYPES`，`WidgetNode.tsx` 从 880 行精简至 475 行。
- 将 `App.tsx` 中的全局快捷键（`Ctrl/Cmd+K`、`Ctrl/Cmd+Z`、`Ctrl/Cmd+Y`）抽离至独立 `useCanvasShortcuts` Hook。

### 3. 首屏 `React.lazy` 分包与原生单线双向连线（`src/core/edgeGraph.ts`、`src/App.tsx`、`src/canvas/ChunkUnderlayCanvas.tsx`）
- 对 `PdfViewerBlock`、`VideoNodeBlock`、`ApiPollerBlock`、`NodeInspectorPanel`、`SearchJumpModal`、`ScriptTrustModal` 实施 `React.lazy` + `Suspense` 按需分包，6 个独立 chunk 成功拆出，首屏主 JS 包从 708 kB 降至 656 kB。
- `BlueprintEdge` 新增 `bidirectional?: boolean`：
  - 近景 React Flow 连线与远景 Canvas 瓦片连线均支持双头箭头（`<——>`）；
  - **右键点击任意连线**即可一键在单向（`——>`）与双向（`<——>`）间切换并入撤销栈；
  - 新增 `getReactiveTargetNodeIds()` 统一驱动单向下游与双向对端联动刷新，内置去重与 `visited` 防死循环保护。
