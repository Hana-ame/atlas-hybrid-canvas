# v45 — 触屏与移动端交互适配（热区放大 / 选中显工具栏 / 底部抽屉 / 防页面回弹）

> 发布日期：2026-11-23

## 改进（Changed）

- **触屏选中即显操作栏**：`src/canvas/WidgetNode.tsx` 将右上角扁平操作栏（还原 / 设置 / 复制 / 删除）改为在 `selected` 或 `group-hover` 时均可见，解决手机/平板无 hover 导致无法点开属性设置与删除的问题。
- **触控热区与手势隔离（`src/index.css` & `src/App.tsx`）**：
  - 全局禁用浏览器橡皮筋回弹（`overscroll-behavior: none`）并在 `.react-flow` 启用 `touch-action: none`、`panOnDrag`、`zoomOnPinch`，单指平移与双指缩放不再与页面滚动打架；
  - 在 `@media (pointer: coarse)` 下将端口锚点放大至 `18px`（附 `34px` 隐形触控热区）、`NodeResizer` 手柄放大至 `16px`、右下角控制按钮放大至 `36px`。
- **小屏响应式底部抽屉与可横滑顶栏**：
  - `< 768px` 时左侧 `TemplateDrawer` 默认折叠，点击模板一键添加到视口中央后自动收起；
  - `TemplateDrawer`（`56vh`）与 `NodeInspectorPanel`（`60vh`）在小屏自动切换为全宽底部抽屉，顶栏支持单行横向滑动不遮挡画布。
