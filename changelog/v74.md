# Atlas Hybrid Canvas v74 — 后端按 Path 分房间全链路实现

## 新增与变更
1. **统一房间路径规范（`src/core/roomPath.ts`）**
   - 前后端共用 `normalizeRoomPath`、`extractRoomPathFromBrowserLocation`、`extractRoomPathFromWsPathname`、`buildRoomWsUrl`、`buildRoomBlueprintUrl` 与 `buildRoomBlueprintPublishUrl`，支持多级路径房间（如 `/team/design`、`/proj-a`），自动拦截 `..` 路径遍历，根路径 `/` 映射为默认房间 `atlas-main`。
2. **WebSocket 按 Path 分房间（`server/roomServer.ts` + `src/core/roomClient.ts`）**
   - 服务端 `upgrade` 握手直接解析 `ws://host/ws/<roomPath>?cid=...`（如 `/ws/team/design?cid=xxx`），同时完整向后兼容旧版 `/ws?room=<name>&cid=...`。
   - 前端 `CollaborativeRoomClient` 改为使用 `buildRoomWsUrl` 发起按路径建连。
3. **REST 蓝图接口与磁盘存储按 Path 隔离（`server/fileStore.ts` + `server/server.ts`）**
   - `server/fileStore.ts` 新增防碰撞 `roomPathToFileKey()`、`createRoomBlueprintStoreRegistry()` 与 `listPersistedRooms()`，不同路径房间的蓝图底座与协同快照完全隔离落盘（默认房间沿用 `blueprint.json` 兼容老数据）。
   - `server/server.ts` 新增：
     - `GET /api/rooms`：查看当前活跃房间与已持久化房间列表；
     - `GET /api/rooms/*/blueprint`：读取指定路径房间的独立蓝图与版本号；
     - `POST /api/rooms/*/blueprint/publish`：发布指定路径房间的独立蓝图；
     - 同时 `/api/blueprint` 与 `/api/blueprint/publish` 也支持通过 `?room=<path>` 或 `X-Room-Path` 指定房间。
4. **前端地址栏与房间自动绑定（`src/App.tsx`）**
   - 打开 `http://host/team/design` 自动进入 `team/design` 房间、拉取该房间独立蓝图并发布到该房间；修改房间名或浏览器前进/后退自动同步路径。
