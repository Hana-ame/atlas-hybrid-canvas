# v55 — 新建 / 复制 / `widgets.create()` 自动寻空位防重叠（仅挪新节点，零副作用）

> 发布日期：2026-11-23

## 新增（Added）

- **自动寻空位模块**（`src/core/placement.ts`）：
  - 实现纯函数 `findNonOverlappingPosition(desired, existing, { gap: 20 })`：若目标位置无 AABB 重叠则原样落点；发生重叠时优先紧贴障碍物右侧/下方顺延，再按螺旋网格向外逐圈探测最近空位。
  - 绝不推动或修改任何已有控件坐标，完全避免破坏用户空间记忆或引发多人协同（CRDT）连锁广播。
- **全入口接入**（`src/App.tsx`）：
  - **模板新建 / 拖放 / 顶栏新建**（`instantiateTemplateAt`）：新节点自动避开现有控件并保留 20px 间距。
  - **复制控件**（`handleDuplicateNode`）：优先落于源控件右侧并自动避让已有节点（顺带补齐 `pushHistory()` 与 `script` 字段复制）。
  - **脚本动态生成**（`widgets.create()`）：批量创建多个子控件时逐个将新占用的矩形追加入 `occupiedBoxes`，保证一批生成的子节点彼此也不重叠。
- **单元测试**：新增 `tests/placement.test.ts`（3 条用例），覆盖空位直落、障碍避让不改已有节点、以及连续 6 次批量生成零重叠。
