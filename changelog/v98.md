# v98 — 修复全仓审查 P1/P2/P3 安全与并发问题，优化 ZONE F 状态机示例控制点

> 发布日期：2026-11-26
> 对应审查报告：`changelog/audit-2026-11-26-全仓库.md`

## 修复（Fixed）

- **WS RPC 客户端 IP 伪造与限流绕过（P1-1）**：`server/roomServer.ts` 将握手期计算的真实 `clientIp` 透传并强制覆写到文本 `rpc_req` 与二进制 `binFrame`，不再采信客户端 JSON 帧内自报的 `clientIp`。
- **冷启动并发水合竞态（P1-2）**：
  - `server/roomServer.ts` 改用 `hydrationPromises` 追踪异步磁盘水合，读盘合并完成后再标记 `hydratedRooms`，且 `flushRoomSnapshot()` 在水合进行中时先 `await`，彻底消除空快照覆盖磁盘蓝图风险。
  - `server/fileStore.ts` 将 `ensureLoaded()` / `ensureHistoryLoaded()` 改为复用 in-flight `Promise`，避免首批并发读写跳过磁盘水合；写盘失败改用 `console.error` 记录而非静默吞错。
- **非 ASCII 房间路径路由解码一致性（P1-3）**：`server/server.ts` 全部 `/api/rooms/(.+)/...` 路由（`/blueprint`、`/blueprint/publish`、`/history`、`/rollback`、`/agent/state`、`/ops`）统一接入 `safeDecodeRoomParam()`，畸形编码一律返回 `400`。
- **脚本沙箱动态 `import()` 静态拦截（P1-4）**：`src/core/scriptSandbox.ts` 将 `'import'` 加入 `BLOCKED_TOKENS`（已核对全部内置模板与种子脚本无误伤）。
- **CRDT 字段版本与顶层 `rev` 对齐（P2-1）**：`src/core/crdt.ts` 的 `computeRecordDiff()` 新增可选 `minBaseRevById` 参数，`src/hooks/useRoomCollaboration.ts` 移除事后只抬高顶层 `rev` 的 `bumpRev()`，确保变更字段的 `fieldRevs` 与顶层 `rev` 同步递增。
- **Agent 输入安全校验补全（P2-2）**：`src/core/agentOps.ts` 对 `defaultVars.contents` 同样执行 `validateBlocksSafety()`，对 `buttons[].code` 执行 `validateScriptSafety()`。
- **优雅停机刷盘与发布串行锁（P2-3 / P2-4）**：`roomServer.close()` 等待 `Promise.allSettled(flushTasks)` 完成后再退出；`/blueprint/publish` 统一纳入 `runSerializedForRoom`，`syncPublishedBlueprint()` 同步清除待执行的 `persistTimers`。
- **Docker 运行环境补齐（P2-5）**：`Dockerfile` 升级为 `node:22-alpine`，`builder` 阶段同步构建 `build:mcp`，`runner` 阶段安装 `poppler-utils` 以支持容器内 PDF 解包。
- **细节收口（P3-1 / P3-2）**：`GET /api/pdf/:id/page/:page` 不再向客户端回显底层 `err.message`；Express 4 异步路由统一包入 `asyncHandler` 转发至 JSON 错误中间件；`useOverlaySync.ts` 切房前自动调用 `flushLocalOverlaySave()`；`App.tsx` 应用脚本 `annotationOps` 的 `imageUrl` 时增加 `isSafeImageUrl()` 校验。

## 改进（Changed）

- **ZONE F 状态机示例连线控制点与间距优化**：微调 ZONE F 上下排纵坐标（标题 `y=1945`、上排 `y=2060`、下排 `y=2355`，上下走廊由 `50px` 扩至 `90px`）并重算 `cancel` / `pause` / `resume` / `reset` / `restart` 5 条曲线控制点，实现 7 条连线对全部 5 张卡片与标题栏 **0 遮挡**，`pause` 与 `resume` 标签间距由 `23px` 拉开至 `44.1px`。

## 已知遗留 / 未生效项

- 脚本沙箱的 `import` 拦截目前位于词法层（`BLOCKED_TOKENS`）；若需彻底阻断 `AsyncFunction` 拼接构造动态 `import()`，后续需结合独立 Worker 路由 CSP `default-src 'none'` 或 sandboxed iframe 载体在浏览器层封堵。
- ZONE F 状态机示例脚本仍采用 `emit('fsm-*', 'enter', ...)` 显式指定目标 ID（未改造为多端口 `emitDownstream` 驱动），本版仅调整示例控制点消除遮挡，未改动示例交互语义。
