# v99 — 放开可配的浏览器直连 HTTP/CORS 模式并在 Docker 中默认关闭强制后端代理

> 发布日期：2026-11-26

## 新增（Added）

- **前端代理开关 `VITE_FORCE_BACKEND_PROXY`**（`src/core/runtimeConfig.ts`、`src/vite-env.d.ts`）：新增 `parseForceBackendProxy()`、`forceBackendProxy()` 与 `shouldUseBackendProxy()`；默认为 `true`（维持原有安全默认），设为 `false` / `0` / `off` / `no` 时放开浏览器同源与跨源 CORS 直连请求。
- **HTTP 按钮直连与请求体支持**（`src/core/httpButton.ts`、`src/core/types.ts`、`src/components/NodeInspectorPanel.tsx`、`src/App.tsx`）：`WidgetButtonSpec` 新增可选 `useProxy` 与 `proxyBody`；属性面板支持按按钮切换「经后端 `/api/proxy` 转发」与可选 POST 请求体，响应写入 `lastHttpStatus` 与 `lastHttpResponse`。

## 改进（Changed）

- **放宽同源相对路径校验**（`src/core/apiPoller.ts`、`src/canvas/ApiPollerBlock.tsx`、`src/canvas/contentBlockRegistry.tsx`、`src/core/widgetTemplates.ts`）：`isSafePollUrl()` 放行任意同源相对 `/` 路径（仍拒绝 `//` 及 `javascript:` / `data:` / `file:`）；`ApiPollerBlock` 与 `tpl-api-poller` 默认 `useProxy` 改为读取 `forceBackendProxy()`，同源相对路径不再强绕 `/api/proxy`，且仅向 `/api/` 路径附带 `proxyHeaders()`。
- **代理白名单支持通配符 `*`**（`server/proxySecurity.ts`、`src/core/apiCore.ts`）：`PROXY_ALLOWED_HOSTS=*` 允许转发任意公网 `http`/`https` 域名，同时仍拦截内网/回环/元数据 IP，且通配符匹配绝不触发 `PROXY_API_KEY` 上游密钥注入。
- **Docker 默认关闭强制后端代理**（`Dockerfile`）：默认注入 `VITE_FORCE_BACKEND_PROXY=false`。

## 验证

- 本地执行 `npm run typecheck`、`npm run build:server`、`npm run build:mcp`、`npm run build` 全部通过；除依赖系统 `mutool`/`pdftoppm` 的 `tests/pdfUnpack.test.ts` 外，其余 196 条 `test()` 用例全部通过（含新增的 `VITE_FORCE_BACKEND_PROXY`、`executeHttpButtonAction`、同源相对路径校验与 `*` 通配符用例）。
