# v23 — `vars` 控形完整交互示例与左侧可拖模板

> 发布日期：2026-11-23

## 新增（Added）

- **交互式 `vars` 控形示例升级**：ZONE D「④ vars 驱动形态演示」卡片新增实时宽高/坐标读数、输入框回车改 `vars.title`，以及一键切换 `vars.type` / `color` / `width` / `height` / `pos` 按钮。
- **左侧模板抽屉新增「vars 控形示例」**：在 `src/core/widgetTemplates.ts` 置顶加入 `tpl-var-morph` 模板，随时拖出即可查看并复用完整脚本。

## 改进（Changed）

- **布局变量变更触发空间索引刷新**：`src/App.tsx` 在脚本执行结果里额外检测 `x` / `y` / `pos` / `width` / `height` 是否被写入，命中时同样刷新 `ChunkManager` 空间索引，避免脚本挪动控件后分块索引滞后。
- **保留变量统一过滤**：`src/canvas/WidgetNode.tsx` 改用 `RESERVED_WIDGET_PROP_VARS` 集合过滤变量面板，此前只排除 `contents`，导致布局类保留键混入变量列表。

## 修正（Fixed）

- **`vite-env.d.ts` 补 `VITE_MOCK_SAVE_KEY` 声明**：`src/core/mockApi.ts` 读取该变量但类型未声明，依赖 `vite/client` 的 `[key: string]: any` 索引签名兜底才没报错，会静默吞掉拼写错误。本次补上显式可选声明。

## 移除（Removed）

- **删除根目录 `CHANGELOG.md`**：变更日志改为仅存放于 `changelog/` 目录，一版一文件，不建任何索引或汇总文件。原单文件中的 v21 及更早历史已完整拆分归档为 `v21.md` / `v19-v20.md` / `v17-v18.md` / `v16.md` / `v1-v15.md`，内容未做删减。
- **新增 `AGENTS.md`**：把变更日志的目录、命名、内容结构与硬性约束写成仓库级约定，供后续协作者遵循。

## 已知遗留 / 未生效项

- **v21 的 hooks 未接线**：`useBlueprintHistory` / `useOverlaySync` 已在 `src/hooks/` 实现并在 `App.tsx` 中导入，但从未被调用。因此「50 步撤销」与「跨页签同步」在本版**仍未生效**，`App.tsx` 依旧直接调用 `saveLocalOverlay`（同步写盘）。按需求暂不补。
- **`npm test` 未进 CI 门禁**：`deploy-pages.yml` 只跑 `typecheck` + `build`；`tsconfig.json` 的 `include` 也不含 `tests`，测试文件的类型错误不会被 `tsc --noEmit` 捕获。
- **`server/server.ts` 的 `proxyRateHits` 无过期清理**：不同 IP 条目永久累积，长期运行存在缓慢内存增长。仅影响自托管 server，不影响 Pages 静态部署。

## 说明

- **`vars.pos` 与 `vars.x` / `vars.y` 的优先级**：两者同时存在时，显式的 `vars.x` / `vars.y` 会覆盖 `vars.pos` 解出的坐标（实现中后者先写入、前者后写入）。脚本里二选一即可，避免出现「改了不生效」的困惑。
