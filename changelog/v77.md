# Atlas Hybrid Canvas v77 — CI 自动测试与 `roomServer.test.ts` 全覆盖

## 本次变更
1. **接入 CI `npm test` 与服务端构建校验**
   - `.github/workflows/deploy-pages.yml`：在 `Typecheck` 之后、`Build` 之前新增 `Run unit tests`（`npm test`）与 `Build server bundle`（`npm run build:server`）步骤，确保每次 `main` 推送及部署前均在真实 `node_modules`（含 `ws`）环境下跑通全部测试。
   - 新增 `.github/workflows/ci.yml`：对所有分支的 `push` 与 `pull_request` 自动触发 `npm run typecheck`、`npm test`、`npm run build` 与 `npm run build:server`。
2. **扩充 `tests/roomServer.test.ts` 覆盖 v74–v76 核心能力**
   - 新增 `/ws/<roomPath>` 按路径分房间隔离测试；
   - 新增服务端 `RoomState.upsert` 字段级 `fieldRevs` 并发无冲突合并测试；
   - 新增 `verifyToken` 拒绝未授权连接及通过 `Sec-WebSocket-Protocol` 子协议鉴权建连测试。
