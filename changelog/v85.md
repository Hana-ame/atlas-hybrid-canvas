## 一、P0 / P1 关键安全与功能修复

1. **P0-1 堵住空 Origin 签发漏洞（`server/server.ts`）**
   - 将 `POST /api/auth/session` 的校验条件由 `if (origin && !isSameOrigin && !isAllowedCorsOrigin)` 收紧为 `if (!origin || (!isSameOrigin && !isAllowedCorsOrigin))`，无 `Origin` 头请求直接返回 `403`。
2. **P1-1 堵住 `X-Forwarded-For` 限流绕过（`server/roomServer.ts`、`server/server.ts`、`.env.example`）**
   - 默认不信任客户端自填的 `X-Forwarded-For`，限流键强制取 `req.socket.remoteAddress`；仅在显式设置 `TRUST_PROXY=true` 时才启用 `app.set('trust proxy', 1)` 并读取 `X-Forwarded-For`。
3. **P1-2 `/api/proxy` 与匿名会话令牌解耦（`server/server.ts`、`.env.example`）**
   - 新增 `PROXY_ACCESS_KEY` 环境变量与 `X-Proxy-Access-Key` 请求头（`crypto.timingSafeEqual` 校验）。
   - 配置 `PROXY_ACCESS_KEY` 时必须提供匹配的 `X-Proxy-Access-Key`；配置 `PROXY_API_KEY`（上游密钥注入）时禁止仅凭匿名会话令牌调用 `/api/proxy` 或 `/api/proxy/binary`，必须提供 `PROXY_ACCESS_KEY` 或 `BLUEPRINT_SAVE_KEY`（若两者均未配则直接 `403` 拒绝）。
4. **P1-3 补齐静态模式按房间隔离存储（`src/core/mockApi.ts`）**
   - 实现 `createBrowserRoomStore(roomPath)` 并注入 `browserDeps.getRoomStore`：默认房间 `atlas-main` 保持既有 IndexedDB key，其余路径按 `atlas-hybrid-mock-server-room:<roomPath>:blueprint|revision` 完全隔离。
5. **P1-A 堵住脚本沙箱嵌套 Worker 逃逸（`src/core/scriptSandbox.ts`、`AGENTS.md`）**
   - 将 `Worker`、`SharedWorker`、`Blob`、`URL`、`WebTransport`、`WebAssembly` 加入 Worker 引导代码的不可写/不可配置运行时置空列表（同时作用于 `self` 与原型）。
   - 更新 `AGENTS.md`，明确「Worker 运行时置空列表是主要安全边界，词法黑名单仅作快速静态反馈」。
