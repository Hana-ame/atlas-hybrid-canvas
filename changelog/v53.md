# v53 — 拉伸控件（WidgetNode / AnnotationNode）实时跟随预览与尺寸胶囊提示

> 发布日期：2026-11-23

## 改进（Changed）

- **拉伸控件实时预览（60fps 跟随，不污染历史栈）**：
  - 此前 `WidgetNode.tsx` 与 `AnnotationNode.tsx` 内层根容器直接绑定 `entity.width / height`（或 `annotation.width / height`），且仅在 `onResizeEnd` 松手后更新，导致拖拽 `NodeResizer` 时只有外框在动、卡片本体与 PDF 内容静止不动。
  - 现为 `WidgetNode.tsx` 与 `AnnotationNode.tsx` 增加组件局部 `liveSize` 状态并在 `<NodeResizer>` 绑定 `onResize`：拖动拉伸过程中卡片宽高、内部布局与 PDF 图片实时跟随缩放预览；松手时 `onResizeEnd` 清空 `liveSize` 并一次性落盘，不产生高频 Undo/Redo 快照或 IndexedDB 写入。
  - 拉伸过程中在控件底部居中浮现实时尺寸胶囊（`{width} × {height}`），松手自动消失。
