# Atlas Hybrid Canvas v76 — 复查发现的 6 项问题修复

## 逐项修复说明
1. **消除跨源 WS 鉴权死锁与同源首屏 Cookie 竞态**
   - `src/core/mockApi.ts`：连后端模式下 `POST /api/auth/session` 直接走 HTTP 请求后端，不再经 WS RPC 转发，避免 WS 握手等 Cookie 的死锁。
   - `src/core/apiClient.ts` & `server/authSession.ts` & `server/roomServer.ts`：新增 `Sec-WebSocket-Protocol` 子协议鉴权（`['atlas-v1', 'atlas-auth.<base64url(token)>']`），`roomServer.ts` 在 `upgrade` 时同时支持 `X-Proxy-Token` 请求头、`atlas_session` HttpOnly Cookie 与 `Sec-WebSocket-Protocol` 子协议，并仅回显 `'atlas-v1'`；全程不向 URL 拼接长期令牌。
   - `src/core/apiClient.ts` & `src/App.tsx`：新增 `waitForAuthSessionReady()`，首屏拉取房间蓝图前等待启动期会话换取完成（带 2s 安全超时）。
2. **补齐房间与蓝图路由的客户端鉴权**
   - `server/server.ts`：`GET /api/room/stats`、`GET /api/rooms`、`GET /api/rooms/*/blueprint`、`POST /api/rooms/*/blueprint/publish`、`/api/blueprint` 及 `/api/blueprint/publish` 统一挂载 `requireClientAuth`（启用 `PROXY_CLIENT_TOKEN` 或 `AUTH_SESSION_SECRET` 时生效，开放模式直通）。
3. **修复纯静态模式下按路径分房间蓝图读写**
   - `src/core/apiCore.ts`：原生匹配 `/api/rooms/*/blueprint` 与 `/api/rooms/*/blueprint/publish`，支持 `getRoomStore` 按房间隔离存储。
   - `src/core/mockApi.ts`：为浏览器 IndexedDB 实现按房间路径隔离的 `createBrowserStore(roomPath)`，不再穿透到 CDN 报 404/返回 HTML。
4. **修复切换房间不重新拉取蓝图**
   - `src/App.tsx`：将房间蓝图加载拆为独立 `useEffect([roomName])`，切换房间或浏览器前进/后退时自动拉取目标房间蓝图（空房间重置为种子蓝图），并带竞态取消保护。
5. **修复 CRDT 同 `rev` 并发新增字段丢失**
   - `src/core/crdt.ts`：`mergeRecordFieldsLWW` 在 `incExists && !curExists` 分支改为仅当 `curRevs?.[key]` 存在更新的墓碑时间戳时才拒绝，避免低 `cid` 客户端同 `rev` 并发新增无冲突字段被丢弃。
6. **统一 `hello` 帧房间名规范化**
   - `src/core/roomClient.ts`：建连成功发送 `{ t: 'hello', room: normalizedRoom, cid }` 与连接 URL 路径保持完全一致。
