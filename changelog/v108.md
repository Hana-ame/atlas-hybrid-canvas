# v108 — 修复悬停条遮挡历史按钮、实现控件级独立历史 diff 与 ElyfnRunnerBlock 异步轮询

> 发布日期：2026-11-27

## 新增（Added）

- **服务端控件级快照差异历史**（`server/fileStore.ts`、`server/server.ts`、`src/core/roomPath.ts`、`src/App.tsx`）：
  - `RoomBlueprintStore.listHistory({ nodeId })` 支持遍历持久化快照并按目标 `nodeId` 计算连续版本差异（区分「创建控件」「删除控件」及具体修改字段：`标题` / `正文` / `位置/尺寸` / `变量` / `按钮` / `脚本` / `锁定` / `外观` / `端口`），不再把全房间无关修改混入单个控件历史。
  - `GET /api/rooms/:room/history?nodeId=...` 与 `GET /api/history?nodeId=...` 支持按 `nodeId` 过滤；前端 `App.tsx` 点击控件历史按钮时独立请求该控件历史并隔离加载状态。
- **`ElyfnRunnerBlock` 支持后台异步与 `/jobs/:id` 轮询**（`src/canvas/ElyfnRunnerBlock.tsx`、`src/canvas/contentBlockRegistry.tsx`、`src/core/types.ts`）：
  - 新增 `asyncMode` / `bindAsyncMode` 配置与 UI「异步」复选框；触发 `?async=1` 或收到 HTTP `202 { async: true, jobId }` 后自动每秒轮询 `GET /jobs/:id` 并展示实时耗时，完成后将结果写入节点 `vars` 供下游消费（带 `AbortController` 卸载/重入清理）。

## 修复（Fixed）

- **消除悬停工具栏遮挡常驻 History 按钮**（`src/canvas/WidgetNode.tsx`）：由于卡片右上角已常驻 `History` + `Lock` 两个按钮（共约 48px），将悬停/选中工具栏的右边距从 `right-6`（24px）调整为 `right-12`，并补充 `aria-pressed` 与激活高亮，彻底解决选中或悬停时无法点击 `History` 的问题。

- `tests/uiComponents.test.ts` 新增 `right-12` 防遮挡、`aria-pressed="true"` 与 `ElyfnRunnerBlock` 异步开关断言。
