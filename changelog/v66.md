# v66 — 默认画布新增交互式有限状态机示例（ZONE F）

## 新增内容
- 在默认种子蓝图（`src/core/seedBlueprint.ts`）的 ZONE E 下方新增 **ZONE F · 交互式有限状态机示例区**（`y = 1975..2490`，与既有节点零重叠）：
  - **4 个实时高亮状态节点**：
    - `fsm-idle`（`IDLE 待机`，初始激活态，亮蓝色 `● ACTIVE`，触发 `start`）
    - `fsm-running`（`RUNNING 运行中`，激活态亮绿色，支持 3 路分支：`pause` / `finish` / `cancel`）
    - `fsm-paused`（`PAUSED 已暂停`，激活态亮琥珀色，支持双向恢复 `resume` 与 `reset`）
    - `fsm-done`（`DONE 已完成`，激活态亮紫色，支持闭环重启 `restart` 回到 `IDLE`）
  - **1 个状态机监视器节点（`fsm-monitor`）**：实时显示当前活跃状态、累计转移次数与最近 3 条状态转移轨迹（含一键清空日志）。
  - **7 条有向/双向闭环转移连线**：`IDLE ↔ RUNNING`、`RUNNING ↔ PAUSED`、`PAUSED → IDLE`、`RUNNING → DONE`、`DONE → IDLE`。
- `tests/seedBlueprint.test.ts` 新增状态机节点、初始激活态与全部 7 条闭环转移连线校验（自动联动零重叠与脚本安全编译检查）。
