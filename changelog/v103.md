# v103 — 控件卡片首屏常驻历史按钮与独立历史浮窗

> 发布日期：2026-11-27

## 新增（Added）

- **控件级历史浮窗 `WidgetHistoryPopover`**（`src/components/WidgetHistoryPopover.tsx`、`src/canvas/WidgetNode.tsx`）：在每个控件卡片右上角工具栏（锁定按钮旁）新增**首屏常驻可见**的「查看控件版本历史」按钮（`History` 图标），无需悬停或进入二级菜单即可直接点击打开该控件的历史浮窗（带 `nodrag nopan nowheel` 与指针事件隔离）。
- **App 与控件历史数据联动**（`src/App.tsx`）：新增 `widgetHistoryNodeId` 状态与 `handleOpenWidgetHistory` 回调，点击控件历史按钮时自动触发 `loadRoomHistory()` 并向对应控件传入历史条目与加载状态；打开属性检查面板时自动收起控件历史浮窗。

## 验证

- `tests/uiComponents.test.ts` 新增 `WidgetNode exposes always-visible history button and WidgetHistoryPopover renders entries` 断言，验证常驻历史按钮、浮窗渲染与倒序版本展示。
- 本地执行 `npm run typecheck`、`npm run build` 均退出码 0；除依赖系统 `mutool`/`pdftoppm` 的 `tests/pdfUnpack.test.ts` 外，其余 200 条 `test()` 用例全部通过。
