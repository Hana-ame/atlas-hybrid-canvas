# v68 — IndexedDB 分级缓存减压（PDF 页面与深层撤销栈卸载落盘）

## 改动摘要
- **升级 `src/core/idbStorage.ts`（`DB_VERSION = 2`）**：
  - 在保留原 `kv` 业务存储表完全兼容的基础上，新增带 `by_touchedAt` 索引的 `cache` 冷缓存表；
  - 提供 `idbCacheGet` / `idbCacheSet` / `idbCacheDelete` / `idbCacheClearPrefix`，写入超上限时自动按 LRU 淘汰最久未访问记录，避免磁盘与内存双膨胀。
- **前端 PDF 解包缓存降压（`src/core/pdfClientUnpack.ts`）**：
  - L1 堆内存缓存上限从每文档 32 页压缩至 **4 页**（同时打开文档上限从 6 降为 3）；
  - L2 渲染结果写入 IndexedDB `cache` 表（全局上限 80 页 LRU 淘汰），翻回冷页直接从 IndexedDB 恢复，既不常驻内存也无需重新跑 `pdf.js` 渲染；销毁文档时按前缀自动清理对应冷缓存。
- **撤销/重做历史栈分层卸载（`src/hooks/useBlueprintHistory.ts`）**：
  - L1 堆内存仅常驻最近 **8 步**快照保证常规 `Ctrl+Z` 零延迟；
  - 第 9–50 步历史快照自动溢出至 IndexedDB `cache` 表，内存仅保留轻量字符串 key；深度撤销时透明从 IndexedDB 读回并清理，页面卸载/关闭时自动清理本会话溢出记录。
- **新增测试（`tests/idbCache.test.ts`）**：验证分级缓存读写、LRU 淘汰顺序及按前缀清理。
