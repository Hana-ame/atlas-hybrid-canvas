# v67 — 图片/视频/图片按钮全面改为纯外链并移除本地 blob 内存占用

## 改动摘要
- **移除所有媒体控件的 `blob:` 与本地二进制文件读取**：
  - `src/canvas/ImageNodeBlock.tsx`：移除 `<input type="file">`、`FileReader.readAsDataURL` 与 `URL.createObjectURL`，仅接受外链 `http/https` 与同源 `/api/` 图片地址。
  - `src/canvas/VideoNodeBlock.tsx`：移除本地视频选择与 `URL.createObjectURL`，仅接受外链 `http/https` 与同源 `/api/` 视频直链。
  - `src/canvas/ImageButtonBlock.tsx`：移除四态贴图本地文件上传与 `FileReader`，改为纯外链 URL 配置面板。
- **收紧 `src/core/mediaHelper.ts` 校验策略**：
  - `isSafeImageUrl()` 拒绝 `blob:` 与大二进制 `data:` URL，仅放行 `http/https`、同源 `/api/` 及 `<= 16KB` 轻量内置 `data:image/svg+xml`；
  - `isSafeVideoUrl()` 拒绝 `blob:` 与 `data:`，仅放行 `http/https` 与同源 `/api/`。
- **全仓 `blob:` / `readAsDataURL` 排查结果**：
  - `src/core/scriptSandbox.ts:756`：单份约 5KB 的 Web Worker 启动脚本缓存（全局仅创建一次，无增长）；
  - `src/App.tsx:358`：导出 JSON 下载临时链接，1 秒后自动 `revokeObjectURL`；
  - `src/canvas/AnnotationNode.tsx:84`：旧背景插图注释的本地选图（已走 Canvas 缩放压缩为 WebP/PNG，无 `blob:`）。
