# v101 — vars 栏支持鼠标拖动横滚，并将版本历史与回档移至独立右侧抽屉

> 发布日期：2026-11-26

## 新增（Added）

- **独立版本历史抽屉 `VersionHistoryDrawer`**（`src/components/VersionHistoryDrawer.tsx`、`src/App.tsx`）：参考 Figma / Notion / Miro 版本历史规范，在顶栏撤销/重做旁新增独立 **`版本历史`** 按钮与按需分包的右侧时间线抽屉（与属性检查面板互斥占位）。按时间倒序展示版本号、操作类型标签（`发布` / `Agent` / `协同` / `回档`）、时间戳、操作者 `actor` 及完整摘要，并高亮当前线上版本。
- **两步确认安全回档**（`src/components/VersionHistoryDrawer.tsx`、`src/App.tsx`）：点击历史版本的「回档至此版本」先展开内联确认与 `X-Blueprint-Save-Key` 输入框（提示回档会追加新 `rollback` 快照且历史仍可随时恢复），消除误触风险。

## 改进（Changed）

- **单行 `vars` 栏支持鼠标左键拖动横滑**（`src/canvas/WidgetNode.tsx`）：新增 `computeHorizontalDragScrollLeft()` 与指针捕获拖拽逻辑（`cursor-grab` / `cursor-grabbing`、`select-none`），左键按住变量条左右拖动即可水平浏览长变量值，同时保留原生 5px 细滚动条直接拖拽与滚轮横滑。
- **精简「保存到后端」弹窗**（`src/App.tsx`）：移除原嵌在保存密钥弹窗底部的「房间修改日志与版本回档」列表，使其专注处理发布密钥校验，仅在左下角保留一键切换至「版本历史与回档」的引导入口。
