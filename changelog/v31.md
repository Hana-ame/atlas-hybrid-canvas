# v31 — 新增 PDF 阅读控件（URL / 本地上传 / 服务端 Proxy、左右翻页与页码跳转）

> 发布日期：2026-11-23

## 新增（Added）

- **声明式 PDF 流式块（`type: 'pdf'`）**：在 `src/core/types.ts` 扩展 `ContentLeafBlock`，新增独立组件 `src/canvas/PdfViewerBlock.tsx` 与纯逻辑工具 `src/core/pdfHelper.ts`。
  - 支持直接输入 `http/https` PDF URL、勾选 `Proxy` 走服务端转发、上传本地 `.pdf` 文件，以及一键加载内置 3 页演示 PDF（离线可测）。
  - 支持「上一页 / 下一页」翻页与页码输入框直达（范围 `1–9999`），当前 `pdfUrl` / `pdfPage` / `pdfUseProxy` 实时写入控件 `vars`，可被下游连线控件读取。
- **服务端二进制代理与 PDF 上传托管**：`server/server.ts` 新增 `GET /api/proxy/binary`（复用白名单、DNS SSRF 拦截、30 次/分钟限流、可选 `X-Proxy-Token` 与 `PROXY_API_KEY` 注入，上限 `15MB`）与 `POST /api/pdf/upload` / `GET /api/pdf/:id`（校验 `%PDF` 魔数头，内存 LRU 最多保留 `20` 份）。
- **模板与首屏示例**：左侧模板抽屉置顶新增「PDF 阅读器（`tpl-pdf-reader`）」，画布 ZONE D 右侧新增「⑤ PDF 阅读控件」示例卡。
- **单元测试**：新增 `tests/pdfHelper.test.ts`（3 条用例），自动化测试总数增至 20 条。

## 已知遗留 / 未生效项

- **纯静态 Pages 部署无 `/api/pdf/upload` 后端**：静态预览模式下上传本地 PDF 会自动降级为浏览器本地 `Blob URL`（刷新页面后需重新选择文件）；自托管 `npm run dev` 下勾选 `Proxy` 上传则由服务端持久化托管在 `/api/pdf/:id`。
