## 本版修复

### 阻断

1. **`checkDag()` 全图分支 / `topoSort()` / `computeTopologicalOrder()` 自环被抹平** —— 自环边被直接 `continue` 丢弃，节点入度停在 0 被当成正常源点出队，`ok` 返回 `true`。改为：自环计入入度（不被当源点）、不进邻接表（出队时不把自身入度减回 0）。
2. **`validateConnectionByWidgets()` 把校验脚本执行失败当成放行** —— 只判了 `r.ok && ...`，`r.ok === false` 时直接落到 `return { ok: true }`。给校验脚本写个语法错误即可绕过禁环。改为：`!r.ok` 一律阻止连线并在状态栏给原因。
3. **子控件 `widgets.connect()` 新建的边不进本批快照** —— `op:'connect'` 只写 `nextEdges` 没写 `createdEdges`，同批子控件 `render` 里 `checkDag()` / `topoSort()` / `widgets.inputs()` 看不到这条边。`op:'remove'` 也未清理 `createdEdges`。已双向补齐。
4. **`checkDag(from, to)` 方向反了** —— 判据写成「从 `f` 出发能否回到 `f`」，导致 `f` 自身在既有环里时任意 `f→x` 都误报成环。改为正确的「从 `t` 出发能否走回 `f`」；路径拼接的 `reverse()` 误用一并修正。
5. **递归截断静默** —— `if (depth > 4) return;` 无任何提示。v38 之后这是环路唯一的运行时兜底，静默返回让用户以为「消息发了但没反应」。改为写状态栏提示。

### 非阻断
