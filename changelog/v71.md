# Atlas Hybrid Canvas v71 — Audit & Completion Release

## 变更背景
针对 v70 四项架构升级（App 拆解与分包、字段级 CRDT 与断线重连、WS RPC 原生二进制帧、无状态 HMAC 会话鉴权）进行了逐项代码核查，捕获并修复了 v70 批量脚本中途异常导致的 3 处接线遗漏。

## 修复与补齐清单
1. **字段级 CRDT 合并（Item 2）**
   - `src/hooks/useRoomCollaboration.ts`：`upsert_node` 移除 `mergeRecordFieldsLWW` 之前的 `beatsLocalAndSynced` 前置拦截，避免同 `rev` 并发修改不同字段时被整条丢弃；同时为 `upsert_ann` 与 `upsert_edge` 统一接入 `mergeRecordFieldsLWW` 字段级合并。
2. **WS RPC 原生二进制帧客户端接线（Item 3）**
   - `src/core/rpcClient.ts`：补全 `ws.binaryType = 'arraybuffer'`，对 `Uint8Array` 请求体走 `encodeBinaryRpcFrame` 原生二进制帧发送，在 `onFrame` 中接入 `decodeBinaryRpcFrame`，并在 `frameToResponse` 中直接消费 `rawBody`，移除冗余的 `bytesToBase64` 转换。
3. **服务端无状态 HMAC 会话鉴权接线（Item 4）**
   - `server/server.ts`：接入 `AUTH_SESSION_SECRET`、`POST /api/auth/session`（签发 1 小时有效期的 HMAC-SHA256 会话令牌），并在 `verifyProxyClientToken` 中同时兼容签名会话令牌与静态 `PROXY_CLIENT_TOKEN`。
   - `src/core/apiClient.ts`：新增 `setRuntimeProxyToken()` 与 `getActiveProxyToken()`，支持运行时动态切换会话令牌。

## 验证结果
- `tsc --noEmit`（排除离线环境缺失 `ws` 类型的 `server/roomServer.ts`）：0 报错。
- `npm run build`（Vite 生产构建）：通过，主包 `230.90 kB`（gzip `72.85 kB`），无 chunk-size 警告。
- 单元测试（非 `ws` 套件）：`100/100` 全部通过。
