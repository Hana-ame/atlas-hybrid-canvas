# v109 — 修复协同房间「浏览器 ↔ MCP」节点同步与叠加层遮蔽问题

> 发布日期：2026-11-27

## 修复（Fixed）

- **联机协同房间编辑直接写入共享底座，打通「浏览器 → MCP」同步**（`src/core/layeredStore.ts`、`src/App.tsx`）：
  - 在 `layeredStore.ts` 中新增 `pickLocalNodePatch`、`applyNodePatchesToBase`、`applyNodePatchesToOverlay` 与 `applyInteractiveNodePatches` 纯函数。
  - 在 `App.tsx` 中引入 `roomStatusRef` 与共享助手 `commitInteractiveNodePatches` 统一处理 `handlePatchNode`、控件拖拽落盘（`widgetFinals`）及锁定开关（`handleToggleLock`）。
  - 当 `roomStatus === 'connected'` 时，人工拖拽坐标、尺寸缩放、标题/正文/脚本/颜色/锁定状态修改将直接递增字段/节点版本（`rev + 1`、`cid: SELF_CID`）写入 `base.nodes`，由 `useRoomCollaboration` 自动发送 `upsert_node` WebSocket 增量至服务端 `RoomState`，从而令 MCP `atlas_inspect_room` 与协作者实时可见。
  - 同时剥离 `overlay.nodePatches` 与 `overlay.runtimeVars` 中已被底座吸收的同名字段，彻底避免离线残留补丁在联机后继续遮蔽远端或 MCP 发起的节点更新（双向同步「MCP → 浏览器」不再被旧补丁掩盖）。
  - 未联机（`roomStatus !== 'connected'`）时保持既有单机本地 `overlay.nodePatches` 行为不变。

- `npm run typecheck`、`npm run build`、`npm run build:server`、`npm run build:mcp` 全部退出码 `0`。
- 全量单元测试 207/208 通过（宿主机唯一未过项为缺 `mutool` 可执行文件的 `tests/pdfUnpack.test.ts`，与环境无关）。
